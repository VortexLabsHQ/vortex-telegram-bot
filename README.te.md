## Vortex ఏమిటి?

Vortex మీ గ్రూపుల్లో మరియు ప్రైవేట్ చాట్ల్లో ఉంటుంది మరియు AI చాట్ మోడల్‌తో ప్రజలకు సమాధానం ఇస్తుంది. మీరు దాని పేరు (డిఫాల్ట్ పేరు **Vortex**)ని అంటే అది రిప్లై చేస్తుంది — అది చాట్ చేయవచ్చు, వెబ్‌ను శోధించవచ్చు, చిత్రాలు తయారు చేయవచ్చు, ధరలను తనిఖీ చేయవచ్చు, జోక్స్ చెప్పవచ్చు, ఫైల్‌లను చదవవచ్చు, వాయిస్ మెసేజులను ట్రాన్స్క్రైబ్ చేయవచ్చు, మరియు ఇంకా చాలా విషయాలు చేయవచ్చు.

ఇది మీ స్వంత సర్వర్‌పై, మీ స్వంత దేశంలో మరియు భాషలో పనిచేస్తుంది. మీరు బాస్: ఒక గోపనీయ `/admin` ప్యానెల్ AI కీలు, వినియోగదారులు, మరియు సెట్టింగ్‌లను నిర్వహించడానికి అనుమతిస్తుంది.

- 🔑 **టోకెన్ పూల్** — అనేక LLM ప్రోవైడర్‌లు మరియు కీలను ఉపయోగించండి, స్వయంచాలకంగా రొటేట్ చేయండి మరియు ఫెయిల్ ఓవర్ చేయండి
- 🖼️ **చిత్రం రూపొందించడం మరియు ఎడిటింగ్** — ఉచితం (DuckAI) లేదా చెల్లింపు ప్రోవైడర్‌లు
- 🔍 **వెబ్ శోధన** — సెల్ఫ-హోస్టెడ్ SearXNG, వికీపీడియా ఫాల్‌బ్యాక్ తో
- 💰 **లైవ్ ధరలు** — ముద్రలు, బంగారం, నూనె, మరియు క్రిప్టో మీ స్థానిక ముద్రలో
- 🕌 **ప్రార్థన సమయాలు**, 🃏 **భాగ్యం**, 😄 **జోక్స్**, 🎲 **డైస్ మరియు సిక్కా ఫ్లిప్స్**
- 📎 **ఫైల్ విశ్లేషణ** మరియు **వాయిస్ ట్రాన్స్క్రిప్షన్**
- 📥 **డౌన్లోడ్స్** — లింక్ పంపండి, మీడియా ఫైల్ వాపస్ పొందండి (45 MB వరకు)
- 🌍 **195 దేశాలు** మరియు **40 భాషలు** — దేశం మరియు భాష వేర్వేరు సెట్టింగ్‌లు
- 🔄 **స్వయంచాలక అప్‌డేటింగ్** — ప్రతిరోజు కొత్త రిలీజ్‌లను తనిఖీ చేస్తుంది మరియు అప్‌డేట్ చేయడానికి ముందు మీకు అడుగుతుంది
- 🛡️ **గోపనీయ /admin ప్యానెల్** — టోకన్లు, వినియోగదారులు, స్టాట్స్, చాట్లు, చిత్రం మోడల్, మేనేజర్లు, శక్తి

## ఇన్స్టాల్ చేయడానికి ముందు

మీకు ఒక సర్వర్ (లేదా ఎప్పుడూ অন్‌లో ఉన్న కంప్యూటర్) **Linux** నడిపిస్తున్నది అవసరం, దానిలో ఈ విషయాలు ఇన్స్టాల్ చేయబడి ఉండాలి:

| ఏమి | ఎలా తనిఖీ చేయాలి | మీకు ఏమి కనిపాలి |
| --- | --- | --- |
| **Python 3.11 లేదా కొత్తవర్షం** | `python3 --version` | `Python 3.11.x` or higher (3.12 and 3.13 work too) |
| **git** | `git --version` | `git version 2.x.x` |
| **curl** | `curl --version` | `curl 7.x.x` or `8.x.x` |
| **systemd** | `systemctl --version` | `systemd 24x` or similar |
| **Docker** *(ఐచ్ఛికం)* | `docker --version` | `Docker version 2x.x.x` — వలెను SearXNG వెబ్ శోధన అవసరమైతే మాత్రమే అవసరం |

ఏదో లేకపోతే, `Debian/Ubuntu` లో ఒక కమాండ్‌తో అన్నీ ఇన్స్టాల్ చేయండి:

```bash
sudo apt update && sudo apt install -y python3 python3-venv python3-pip git curl
```

ఐచ్ఛిక `docker` కోసం (మీకు `SearXNG` వెబ్ శోధన అవసరమైతే మాత్రమే):

```bash
sudo apt install -y docker.io
sudo systemctl enable --now docker
sudo usermod -aG docker $USER
```

చివరి లైన్ తర్వాత, లాగ్ అవుట్ చేసి మళ్లీ లాగ్ ఇన్ అవ్వండి (లేదా `docker` కమాండ్‌లను `sudo` తో రన్ చేయండి). ఇన్స్టాలర్ `Debian/Ubuntu` పై `apt` తో మిసింగ్ సాధనాలను మీకు ఇన్స్టాల్ చేయడానికి عرضه చేస్తుంది. ఇతర సిస్టమ్‌లలో, మొదట మీ ప్యాకేజ్ మేనేజర్‌తో అవి ఇన్స్టాల్ చేయండి. `systemd` సిస్టమ్‌తో పాటు వస్తుంది — అది వేరేగా ఇన్స్టాల్ చేయలేము.

మీకు Telegram నుండి రెండు విషయాలు కూడా అవసరం (రెండూ ఉచితం):

1. **ఒక బాట్ టోకెన్** — Telegramలో [@BotFather](https://t.me/BotFather)తో మాట్లాడండి, `/newbot` పంపండి, మరియు అది ఇచ్చే టోకెన్‌ను కాపీ చేయండి.
2. **మీ సంఖ్యాత్మక Telegram వినియోగదారు ID** — [@userinfobot](https://t.me/userinfobot)తో మాట్లాడండి మరియు అది చూపించే నంబర్‌ను కాపీ చేయండి. ఇది మీ "బాస్" ID: మాత్రమే ఈ అకౌంట్ `/admin`ని ఉపయోగించవచ్చు.

## ఇన్స్టాల్ చేయండి

ఒక కమాండ్. దానిని కాపీ చేయండి, మీ టెర్మినల్‌లో పేస్ట్ చేయండి, మరియు Enter నొక్కండి:

```bash
curl -sSL https://raw.githubusercontent.com/VortexLabsHQ/vortex-telegram-bot/main/install.sh | bash
```

ఇన్స్టాలర్ మీకు ఆరు ప్రశ్నలు అడుగుతుంది, క్రమంలో:

1. **దేశం** — **[దేశ సारणిలో](#countries) క్రింద ఇవ్వబడినట్లుగా** మీ దేశం యొక్క ఇంగ్లీషు పేరును అంచుకోండి (ఉదాహరణకు `Turkey`)। దేశం సమయ మండలం, ధరల కోసం స్థానిక ముద్ర, ప్రార్థన సమయాలు, మరియు స్థానిక కంటెంట్‌ను సెట్ చేస్తుంది.
2. **భాష** — బాట్ మాట్లాడే భాష (ఉదాహరణకు `en`, `fa`, `tr`)। మీ దేశానికి డిఫాల్ట్‌ను అంగీకరించడానికి ఎంటర్ నొక్కండి। భాష దేశం నుండి వేరుగా ఉంటుంది: ఇది బాట్ ఏమి చెబుతుందో మాత్రమే మారుస్తుంది, మరియు మీరు దీన్ని `/admin` నుండి తర్వాత మార్చవచ్చు.
3. **బాట్ టోకెన్** — [@BotFather](https://t.me/BotFather) నుండి టోకెన్‌ను అంచుకోండి। ఇన్స్టాలర్ Telegramతో లైవ్‌గా దీన్ని తనిఖీ చేస్తుంది.
4. **బాస్ న్యూమెరిక్ ID** — [@userinfobot](https://t.me/userinfobot) నుండి మీ Telegram యూజర్ ID.
5. **బాట్ పేరు / వేక్ వర్డ్** — గ్రూప్‌లలో బాట్‌తో మాట్లాడటానికి ప్రజలు అంటున్న పేరు. ఏ భాషా సమస్య లేదు (ఉదాహరణకు `Vortex` లేదా `ورتکس`)। డిఫాల్ట్ `Vortex` కోసం ఎంటర్ నొక్కండి.
6. **మొదటి LLM ప్రావైడర్** — ఒకటి ఎంచుకోండి: OpenAI, Anthropic, OpenRouter, Google AI (Gemini), DeepSeek, Groq, Together AI, Mistral AI, xAI (Grok), Cohere, లేదా **కస్టమ్** (బేస్ URL అంచుకోండి). అప్పుడు ఆ ప్రావైడర్‌కు మీ API కీని అంచుకోండి — ఇన్స్టాలర్ ప్రావైడర్ యొక్క లైవ్ మోడల్ జాబితాను తీసుకురావచ్చు మరియు మీరు ఒక మోడల్‌ను ఎంచుకుంటారు.

అప్పుడు ఇన్స్టాలర్ డిపెండెన్సీలను ఇన్స్టాల్ చేస్తుంది, `.env` ఫైల్‌ను రాయుతుంది, `vortex-bot` systemd సేవను సృష్టిస్తుంది, వెబ్ శోధన కోసం SearXNGని ఇన్స్టాల్ చేయడానికి ఆఫర్ చేస్తుంది (Docker అవసరం), మరియు బాట్‌ను ప్రారంభిస్తుంది.

> ⚠️ **Anthropic నేరుగా పనిచేయదు.** Anthropic యొక్క నేటివ్ API OpenAI-కంపాటిబుల్ కాదు, మరియు ఈ బాట్ మాత్రమే OpenAI-కంపాటిబుల్ APIలతో మాట్లాడుతుంది. మీరు Anthropicని ఎంచుకున్నట్లయితే, ఇన్స్టాలర్ హెచ్చరిస్తుంది: కీ మাত্র OpenAI-కంపాటిబుల్ గేట్వే ద్వారా పనిచేస్తుంది. బదులుగా OpenRouterని, లేదా జాబితాలోని మరో ప్రావైడర్‌ని ఉపయోగించండి.

## ఇన్స్టాల్ చేసిన తర్వాత

బాట్ రన్నింగ్‌లో ఉందో తనిఖీ చేయండి:

```bash
systemctl status vortex-bot
```

మీరు `active (running)`ని చూడాలısını. లైవ్ లాగ్‌ను చూడటానికి:

```bash
journalctl -u vortex-bot -f
```

ఇప్పుడు Telegramని తెరవి మీ బాట్‌తో మాట్లాడండి:

- `/start` పంపండి — బాట్ హలో అంటుంది.
- **ప్రైవేట్ చాట్**లో, దానిని రాసి — వేక్ వర్డ్ అవసరం లేదు.
- **గ్రూప్** లో, బాట్‌ను గ్రూప్‌కు జోడించండి, తరువాత గ్రూప్ ప్రైవేసీని మూసివేయండి: [@BotFather](https://t.me/BotFather) లో `/setprivacy` పంపండి, మీ బాట్‌ను ఎంచుకోండి, మరియు **Disable** ఎంచుకోండి — లేకపోతే బాట్ గ్రూప్ సందేశాలను చూడలేదు మరియు వేక్ వర్డ్‌ను వినలేదు. అప్పుడు దాని పేరు చెప్పండి, ఉదాహరణకు: `Vortex what's the time?`
- బాస్గా, ప్రైవేట్ చాట్‌లో `/admin` పంపి లుక్కిన అడ్మిన్ ప్యానెల్‌ను తెరవండి.

**అప్డేట్స్ స్వయంచాలకంగా.** రోజుకు ఒకసారి బాట్ GitHubలో కొత్త రిలీజ్‌ని తనిఖీ చేస్తుంది. ఒకటి ఉంటే, ఇది మీకు ✅ / ❌ బటన్లతో ఒక ప్రైవేట్ మెసేజ్‌ను పంపుతుంది. ✅ని నొక్కండి, అది స్వయంగా అప్డేట్ అవుతుంది మరియు రీస్టార్ట్ అవుతుంది — మీరు సర్వర్‌ను ఎప్పుడూ తాకాలి లేదు.

## కాన్ఫిగరేషన్

అన్ని సెట్టింగ్స్ ఇన్స్టాల్ డైరెక్టరీలోని `.env` ఫైల్‌లో ఉంటాయి. ప్రతి ఆప్షన్‌కు [`.env.example`](.env.example)ని చూడండి. అత్యంత ముఖ్యమైనవి:

| Setting | What it does |
| --- | --- |
| `BOT_TOKEN` | మీ Telegram బాట్ టోకెన్ (@BotFather నుండి) |
| `BOSS_ID` | మీ న్యూమెరిక్ Telegram యూజర్ ID (బాట్ ఓవ్నర్) |
| `BOT_NAME` | బాట్ పేరు మరియు గ్రూపుల్లో వేక్ వర్డ్ (డిఫాల్ట్ `Vortex`) |
| `BOT_COUNTRY` | దేశం ఇంగ్లీష్లో, ఉదా. `United States` (టైమ్ జోన్, కరెన్సీ, ప్రార్థన సమయాలను సెట్ చేస్తుంది) |
| `BOT_LANGUAGE` | బాట్ భాష కోడ్, ఉదా. `en`, `fa`, `tr` (బాట్ ఏమి చెబుతుందో మాత్రమే మారుతుంది) |
| `LLM_PROVIDERS` | LLM ప్రావైడర్స్ మరియు కీలు: `base_url\|api_key\|model`, కామా-విభజితం |
| `UPDATE_CHECK_ENABLED` | `1` = రోజువారి అప్‌డేట్‌లను తనిఖీ చేయండి, `0` = ఎప్పుడూ తనిఖీ చేయకండి |
| `UPDATE_REPO` | రిలీజులను పర్యవేక్షించే రిపో (డిఫాల్ట్ `VortexLabsHQ/vortex-telegram-bot`) |
| `SEARCH_PROVIDER` | వెబ్ శోధన: `searxng` (డిఫాల్ట్), `tavily`, లేదా `serper` |
| `DAILY_LIMIT_MESSAGES` | యూజర్ ప్రతి రోజు మాక్స్ బాట్ రిప్లైలు (డిఫాల్ట్ `30`, బాస్ ముఫ్త్) |

దేశం మరియు భాషను తరువాత `/admin` ప్యానెల్ (Language & Country) నుండి కూడా మార్చవచ్చు, ఏ ఫైల్‌ను సవరించకుండా.

## Docker বিকల్పం

ఇన్స్టాలర్‌కు బదులుగా Docker ని ప్రియపడతే:

```bash
cp .env.example .env   # fill in BOT_TOKEN, BOSS_ID, and your LLM key(s)
docker compose up -d --build
```

ఇది బాట్‌ను సెల్ఫ-హోస్టెడ్ SearXNG శోధన ఇంజిన్‌తో పాటు ప్రారంభిస్తుంది. `docker compose logs -f bot` తో లాగ్స్ చూడండి.

గమనిక: ఆటోమేటిక్ సెల్ఫ్-అప్‌డేటర్ systemd సేవను అవసరం చేస్తుంది, కాబట్టి Docker లో అప్‌డేట్‌లు మాన్యువల్: `git pull` మరియు తర్వాత `docker compose up -d --build` మళ్లీ.

## ఫీచర్స్ వివరంగా

### /admin ప్యానెల్

ప్రైవేట్ చాట్‌లో `/admin` పంపండి (బాస్ మాత్రమే — ఇతర ఎవరూ తెరవలేరు, మరియు `/help` లేదా మెనుల్లో ఎప్పుడూ కనిపించదు). ఇందులో:

- 🔑 **Tokens & model** — LLM కీలు జోడించండి లేదా తొలగించండి, ఏ కీలు ఆరోగ్యకరంగా ఉన్నాయి అనేది చూడండి, సక్రియ మోడల్‌ను ఎంచుకోండి, ప్రావైడర్ యొక్క లైవ్ మోడల్ లిస్ట్‌ను బ్రౌజ్ చేయండి
- 👥 **Users** — యూజర్ కౌంట్లు, బాన్ / আন్బాన్, అలౌలిస్ట్
- 📊 **Stats** — వినియోగ సంఖ్యలు
- 💬 **Recent chats** — ప్రజలు బాట్‌కు ఏమి చెప్పారో (బాస్ మాత్రమే, ప్రైవేట్)
- 🖼️ **Image model** — DuckAI (ఉచితం, డిఫాల్ట్), HiLinkUp, కస్టమ్ ఇమేజ్ సేవ, లేదా ఆఫ్
- 🛡️ **Managers** — విశ్వాసార్హులకు ప్యానెల్ భాగాలకు యాక్సెస్ ఇవ్వండి
- 🟢/🔴 **Power** — బాట్‌ను அனందరికీ অন్ లేదా ఆఫ్ చేయండి (బాస్ నియంత్రణలో ఉంటారు)
- 🌍 **Language & Country** — బాట్ భాష లేదా దేశాన్ని ఎప్పుడూ మార్చండి

### టోకెన్ పూల్

బాట్ అనేక LLM ప్రావైడర్ కీలను ఒకసారి ধारणించవచ్చు. ఇది ఆరోగ్యకర కీలల మధ్య రొటేట్ అవుతుంది మరియు ఒకటి పనిచేయకపోతే ఆటోమేటిక్ ఫెయిల్‌ఓవర్ అవుతుంది. `/admin` నుండి ఒక మోడల్‌ను పిన్ చేయవచ్చు, మానువల్ మోడల్ ఎంచుకోవచ్చు, లేదా బాట్‌ను స్వచ్ఛందంగా రొటేట్ చేయవచ్చు. OpenAI-కంపాటిబుల్ API ఉన్న ఏ ప్రావైడర్‌నీ కూడా పనిచేస్తుంది — చిన్న అగ్రిగేటర్స్ కూడా, పెద్ద పేర్లు మాత్రమే కాదు.

### చిత్రాలు

చిత్ర జనరేషన్ మూడు మోడ్‌లలో ఉంది: **DuckAI** (ఉచితం, కీ అవసరం లేదు, డిఫాల్ట్), **HiLinkUp** (పేడ్, మంచి నాణ్యత), లేదా **కస్టమ్** OpenAI-కంపాటిబుల్ ఇమేజ్ సేవ. మీరు బాట్‌కు ఫోటో పంపి దానిని ఎలా ఎడిట్ చేయాలి అని చెప్పవచ్చు ("ఇది కార్టూన్ శైలిలో చేయండి"), అది కొత్త చిత్రాన్ని జనరేట్ చేస్తుంది. చిత్ర జనరేషన్ `/admin` నుండి ఆఫ్ చేయవచ్చు.

### దేశాలు మరియు భాషలు

Vortex **195 దేశాలు** మరియు **40 భాషలను** మద్దతు ఇస్తుంది. దేశం సమయ మండలం, ధరలు ఎప్పటికి చూపబడతాయి, ప్రార్థన సమయాలకు ఉపయోగించే నగరం, మరియు స్థానిక కంటెంట్‌ను సెట్ చేస్తుంది. భాష మాత్రమే బాట్ ఏమి చెబుతుందో సెట్ చేస్తుంది — ఉదాహరణకు బెల్జియంలోని ఒక గ్రూపు దేశం బెల్జియం మరియు భాష ఇంగ్లీష్‌ను ఉపయోగించవచ్చు. రెండూ `/admin` నుండి తర్వాత మార్చవచ్చు.

### అప్‌డేట్స్

బాట్ `VortexLabsHQ/vortex-telegram-bot` యొక్క GitHub రిలీజులను రోజుకు ఒకసారి తనిఖీ చేస్తుంది. కొత్త వెర్షన్ వచ్చినప్పుడు, బాస్‌కు ✅ / ❌ బటన్లతో సందేశం పంపుతుంది. అంగీకరించడం కోడ్‌ను అప్‌డేట్ చేసి బాట్‌ను రీస్టార్ట్ చేస్తుంది. రిపో ప్రైవేట్ ఉన్నప్పుడు, తనిఖీ సైలెంట్‌గా ఏమి చేయదు (GitHub APIకు పబ్లిక్ రిపో అవసరం) — `UPDATE_CHECK_ENABLED=0` సెట్ చేయండి మీరు ఎప్పుడూ తనిఖీ కోరకపోతే.

## సమస్య పరిష్కారం / FAQ

**ఇన్స్టాలర్ నా టోకెన్ అవ్యవహార్యం అని చెబుతోంది.**
టోకెన్ [@BotFather](https://t.me/BotFather) నుండి వస్తుంది. మీరు పూర్తి టోకెన్ (అంకెలా, తర్వాత కోలన్, 35+ అక్షరాలు) కాపీ చేసారని, ఎక్స్ట్రా స్పేస్‌లు లేకుండా నిర్ధారించుకోండి. మీరు బాట్‌ను డిలీట్ చేసినా లేదా కొత్త టోకెన్ తయారుచేసినా, పురాతనది పనిచేయదు — కొత్తదానిని పేస్ట్ చేయండి.

**బాట్ నా గ్రూపులో జవాబు ఇవ్వదు.**
చెక్ చేయాల్సిన నాలుగు విషయాలు: (1) గ్రూప్ ప్రైవేసీ ఆఫ్‌గా ఉండాలి — [@BotFather](https://t.me/BotFather) లో `/setprivacy` పంపండి, మీ బాట్‌ను ఎంచుకోండి, మరియు **Disable** ఎంచుకోండి; ప్రైవేసీ ఆన్‌గా ఉంటే, బాట్ గ్రూప్ సందేశాలను ఎప్పుడూ చూడలేదు, (2) బాట్ గ్రూప్‌కు జోడించబడాలి, (3) మీరు దాని వేక్ వర్డ్‌ను చెప్పాలి — దాని పేరు, ఉదాహరణకు `Vortex what's the time?` — బాట్ గ్రూప్‌లలో దాని పేరు చెప్పినప్పుడు మాత్రమే వినుతుంది, (4) ప్రైవేట్ చాట్‌లో వేక్ వర్డ్ అవసరం లేదు.

**బాట్ ఇంగ్లీష్లో జవాబు ఇస్తుంది, నా భాషలో కాదు.**
`/admin` (బాస్ మాత్రమే) → Language & Country పంపండి, మరియు మీ భాషను ఎంచుకోండి. ఇన్స్టాలర్ కూడా భాషను అడిగుతుంది — అక్కడ Enter నొక్కి మీ దేశం యొక్క డిఫాల్ట్‌ను అంగీకరించండి.

**నేను Anthropicని ఎంచుకున్నాను మరియు బాట్ చాట్ చేయదు.**
Anthropic యొక్క నేటివ్ API OpenAI-కంపాటిబుల్ కాదు, కాబట్టి బాట్ దానితో నేరుగా చాట్ చేయలేదు. OpenRouterని ఉపయోగించండి (ఇది OpenAI-కంపాటిబుల్ API ద్వారా Claude మోడల్స్‌ను సర్వ్ చేయగలదు), లేదా జాబితా నుండి మరొక ప్రావైడర్‌ను ఎంచుకోండి.

**వెబ్ సెర్చ్ పనిచేయదు.**
వెబ్ సెర్చ్‌కు SearXNG అవసరం, దాన్ని ఇన్స్టాలర్ Dockerతో సెట్ చేయడానికి అందిస్తుంది. దానివి లేకపోతే, బాట్ Wikipediaకు ఫాల్ బ్యాక్ అవుతుంది, అది బలహీనంగా ఉంటుంది. మీరు `.env` లో `SEARCH_API_KEY`తో `SEARCH_PROVIDER=tavily` లేదా `serper` సెట్ చేయవచ్చు.

**లాగ్స్ ఎక్కడ ఉన్నాయి?**
`journalctl -u vortex-bot -f` లైవ్ లాగ్ చూపిస్తుంది. `systemctl status vortex-bot` సర్వీస్ రన్నింగ్ అయినా లేదో చూపిస్తుంది. బాట్ ఆపినప్పుడు, `sudo systemctl restart vortex-bot` మళ్లీ ప్రారంభిస్తుంది.

**బాట్ నేను డైలీ లిమిట్ చేరుకున్నాను అని చెబుతోంది.**
ప్రతి వినియోగదారు రోజుకు 30 బాట్ రిప్లైలు పొందుతారు (బాస్ ముచ్చివేయబడ్డారు). లిమిట్ బాట్ యొక్క దేశం యొక్క సమయ మండలంలో అర్ధరాత్రి రీసెట్ అవుతుంది. `.env` లో `DAILY_LIMIT_MESSAGES`తో పెంచండి, లేదా బాస్‌ను అడగండి.

**నాకు బగ్ దొరుకింది / నాకు ఒక ఆలోచన ఉంది.**
దయచేసి GitHub పై ఇష్యూ తెరవండి — [CONTRIBUTING.md](CONTRIBUTING.md) చూడండి ఎలా రిపోర్ట్ చేయాలి మరియు ఫిక్స్ ఎలా పంపాలి.

## డెవలప్‌మెంట్

```bash
git clone https://github.com/VortexLabsHQ/vortex-telegram-bot.git
cd vortex-telegram-bot

python3.11 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
pip install ruff

cp .env.example .env   # then fill in your own BOT_TOKEN and LLM key(s)
python -m bot.main
```

టెస్ట్‌లను రన్ చేయండి (సాధారణ Python స్క్రిప్ట్లు, pytest అవసరం లేదు):

