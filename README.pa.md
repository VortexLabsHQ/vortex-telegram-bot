## ਵੋਰਟੈਕਸ ਕੀ ਹੈ?

ਵੋਰਟੈਕਸ ਇੱਕ ਟੈਲੀਗ੍ਰਾਮ ਬੋਟ ਹੈ ਜੋ ਤੁਹਾਡੇ ਗਰੁੱਪਾਂ ਅਤੇ ਨਿੱਜੀ ਚੈਟਾਂ ਵਿੱਚ ਰਹਿੰਦਾ ਹੈ ਅਤੇ ਏਆਈ ਚੈਟ ਮਾਡਲ ਨਾਲ ਲੋਕਾਂ ਦੇ ਜਵਾਬ ਦਿੰਦਾ ਹੈ। ਤੁਸੀਂ ਇਸਦਾ ਨਾਮ ਲੈਂਦੇ ਹੋ (ਡਿਫਾਲਟ ਨਾਮ **ਵੋਰਟੈਕਸ** ਹੈ) ਅਤੇ ਇਹ ਜਵਾਬ ਦਿੰਦਾ ਹੈ — ਇਹ ਗੱਲਬਾਤ ਕਰ ਸਕਦਾ ਹੈ, ਵੈੱਬ ਖੋਜ ਸਕਦਾ ਹੈ, ਤਸਵੀਰਾਂ ਬਣਾ ਸਕਦਾ ਹੈ, ਕੀਮਤਾਂ ਚੈਕ ਕਰ ਸਕਦਾ ਹੈ, ਚੁਟਕੁਲੇ ਸੁਨਾ ਸਕਦਾ ਹੈ, ਫਾਇਲਾਂ ਪੜ੍ਹ ਸਕਦਾ ਹੈ, ਆਵਾਜ਼ ਦੇ ਸੁਨੇਹੇ ਟ੍ਰਾਂਸਕ੍ਰਾਇਬ ਕਰ ਸਕਦਾ ਹੈ, ਅਤੇ ਹੋਰ ਵੀ ਬਹੁਤ ਕੁਝ।

ਇਹ ਤੁਹਾਡੇ ਆਪਣੇ ਸਰਵਰ 'ਤੇ ਚੱਲਦਾ ਹੈ, ਤੁਹਾਡੇ ਆਪਣੇ ਦੇਸ਼ ਅਤੇ ਭਾਸ਼ਾ ਵਿੱਚ। ਤੁਸੀਂ ਮਾਲਕ ਹੋ: ਇੱਕ ਲੁਕਿਆ ਹੋਇਆ `/admin` ਪੈਨਲ ਤੁਹਾਨੂੰ ਏਆਈ ਕੁੰਜੀਆਂ, ਯੂਜ਼ਰਾਂ, ਅਤੇ ਸੈਟਿੰਗਾਂ ਨੂੰ ਪ੍ਰਬੰਧਿਤ ਕਰਨ ਦਿੰਦਾ ਹੈ।

## ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ

- 💬 **AI ਚੈਟ** ਗਰੁੱਪਾਂ ਵਿੱਚ (ਵੇਕ ਵਰਡ) ਅਤੇ ਨਿੱਜੀ ਚੈਟਾਂ ਵਿੱਚ (ਕੋਈ ਵੇਕ ਵਰਡ ਲੋੜੀਂਦਾ ਨਹੀਂ)
- 🔑 **ਟੋਕਨ ਪੂਲ** — ਕਈ LLM ਪ੍ਰੋਵਾਈਡਰ ਅਤੇ ਕੀਜ਼ ਵਰਤੋ, ਆਪੇ-ਹੀ ਰੋਟੇਟ ਅਤੇ ਫੇਲਓਵਰ ਕਰੋ
- 🖼️ **ਤਸਵੀਰ ਜਨਰੇਸ਼ਨ** — ਆਪਣੀ ਇਮੇਜ ਸਰਵਿਸ (ਬੇਸ URL + API ਕੁੰਜੀ + ਮਾਡਲ) ਨਾਲ, `/admin` ਵਿੱਚ ਸ਼ਾਮਲ ਕੀਤੀ ਗਈ
- 🔍 **ਵੈਬ ਖੋਜ** — ਸਵੈ-ਹੋਸਟਡ SearXNG, ਵਿਕੀਪੀਡੀਆ ਫਾਲਬੈਕ ਨਾਲ
- 💰 **ਲਾਈਵ ਕੀਮਤਾਂ** — ਕਰੰਸੀ, ਸੋਨਾ, ਤੇਲ, ਅਤੇ ਕ੍ਰਿਪਟੋ ਤੁਹਾਡੀ ਸਥਾਨਕ ਕਰੰਸੀ ਵਿੱਚ
- 🕌 **ਨਿਮਾਜ਼ ਦੇ ਸਮਾਂ**, 🃏 **ਕਿਸਮਤ**, 😄 **ਚੁਟਕੁਲੇ**, 🎲 **ਪਾਸੇ ਅਤੇ ਸਿੱਕੇ ਉਛਾਲਨਾ**
- 📎 **ਫਾਇਲ ਵਿਸ਼ਲੇਸ਼ਣ** ਅਤੇ **ਆਵਾਜ਼ ਦਾ ਲਿਖਤ ਰੂਪ**
- 📥 **ਡਾਊਨਲੋਡ** — ਲਿੰਕ ਭੇਜੋ, ਮੀਡੀਆ ਫਾਇਲ ਵਾਪਸ ਪਾਓ (45 MB ਤੱਕ)
- 🌍 **195 ਦੇਸ਼** ਅਤੇ **40 ਭਾਸ਼ਾਵਾਂ** — ਦੇਸ਼ ਅਤੇ ਭਾਸ਼ਾ ਵੱਖ-ਵੱਖ ਸੈਟਿੰਗ ਹਨ
- 🔄 **ਸਵੈ-ਅਪਡੇਟਿੰਗ** — ਹਰ ਰੋਜ਼ ਨਵੀਆਂ ਰਿਲੀਜ਼ ਚੈੱਕ ਕਰਦਾ ਹੈ ਅਤੇ ਅਪਡੇਟ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਤੁਹਾਨੂੰ ਪੁੱਛਦਾ ਹੈ
- 🛡️ **ਛੁਪਾ /admin ਪੈਨਲ** — ਟੋਕਨ, ਯੂਜ਼ਰ, ਸਟੈਟਸ, ਚੈਟ, ਤਸਵੀਰ ਮਾਡਲ, ਮੈਨੇਜਰ, ਪਾਵਰ

## ਇੰਸਟਾਲ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ

ਤੁਹਾਨੂੰ ਇੱਕ ਸਰਵਰ (ਜਾਂ ਇੱਕ ਕੰਪਿਊਟਰ ਜੋ ਚਾਲੂ ਰਹੇ) ਦੀ ਲੋੜ ਹੈ ਜੋ **Linux** ਚਲਾ ਰਿਹਾ ਹੋ ਅਤੇ ਜਿਸ ਵਿੱਚ ਇਹ ਇੰਸਟਾਲ ਹੋਏ ਹੋਏ ਹਨ:

| ਕੀ | ਕਿਵੇਂ ਚੈੱਕ ਕਰਨਾ ਹੈ | ਤੁਹਾਨੂੰ ਕੀ ਦੇਖਣਾ ਚਾਹੀਦਾ ਹੈ |
| --- | --- | --- |
| **Python 3.11 ਜਾਂ ਨਵਾਂ** | `python3 --version` | `Python 3.11.x` ਜਾਂ ਉੱਚਾ (3.12 ਅਤੇ 3.13 ਵੀ ਕੰਮ ਕਰਦੇ ਹਨ) |
| **git** | `git --version` | `git version 2.x.x` |
| **curl** | `curl --version` | `curl 7.x.x` ਜਾਂ `8.x.x` |
| **systemd** | `systemctl --version` | `systemd 24x` ਜਾਂ ਇਸਦੇ ਜਿਹਾ |
| **Docker** *(ਵਿਕਲਪਿਕ)* | `docker --version` | `Docker version 2x.x.x` — ਸਿਰਫ਼ ਲੋੜ ਹੈ ਜੇ ਤੁਸੀਂ ਵਿਕਲਪਿਕ SearXNG ਵੈਬ ਖੋਜ ਚਾਹੁੰਦੇ ਹੋ |

ਜੇ ਕੁਝ ਛੁੱਟ ਗਿਆ ਹੈ, ਤਾਂ ਇੱਕ ਕਮਾਂਡ ਨਾਲ ਸਭ ਕੁਝ ਇੰਸਟਾਲ ਕਰੋ (`Debian/Ubuntu`):

```bash
sudo apt update && sudo apt install -y python3 python3-venv python3-pip git curl
```

ਵੈਕਲਪਿਕ `Docker` ਲਈ (ਸਿਰਫ਼ ਜੇ ਤੁਸੀਂ `SearXNG` ਵੈੱਬ ਖੋਜ ਚਾਹੁੰਦੇ ਹੋ):

```bash
sudo apt install -y docker.io
sudo systemctl enable --now docker
sudo usermod -aG docker $USER
```

ਆਖਰੀ ਲਾਈਨ ਤੋਂ ਬਾਅਦ, ਲੌਗ ਆਉਟ ਕਰਕੇ ਵਾਪਸ ਲੌਗ ਇਨ ਕਰੋ (ਜਾਂ `docker` ਕਮਾਂਡਾਂ ਨੂੰ `sudo` ਨਾਲ ਚਲਾਓ)। ਇੰਸਟਾਲਰ ਤੁਹਾਨੂੰ `apt` ਨਾਲ `Debian/Ubuntu` 'ਤੇ ਗੁੰਮ ਹੋਏ ਟੂਲ ਇੰਸਟਾਲ ਕਰਨ ਦੀ ਪੇਸ਼ਕਸ਼ ਵੀ ਕਰਦਾ ਹੈ। ਦੂਜੇ ਸਿਸਟਮਾਂ 'ਤੇ, ਪਹਿਲਾਂ ਆਪਣੇ ਪੈਕੇਜ ਮੈਨੇਜਰ ਨਾਲ ਉਹ ਇੰਸਟਾਲ ਕਰੋ। `systemd` ਸਿਸਟਮ ਨਾਲ ਆਉਂਦਾ ਹੈ — ਇਸ ਨੂੰ ਅਲੱਗ ਤੋਂ ਇੰਸਟਾਲ ਨਹੀਂ ਕੀਤਾ ਜਾ ਸਕਦਾ।

ਤੁਹਾਨੂੰ Telegram ਤੋਂ ਦੋ ਚੀਜ਼ਾਂ ਦੀ ਵੀ ਲੋੜ ਹੈ (ਦੋਵੇਂ ਮੁਫ਼ਤ ਹਨ):

1. **ਇੱਕ ਬਾਟ ਟੋਕਨ** — Telegram 'ਤੇ [@BotFather](https://t.me/BotFather) ਨਾਲ ਗੱਲ ਕਰੋ, `/newbot` ਭੇਜੋ, ਅਤੇ ਜੋ ਟੋਕਨ ਉਹ ਦਿੰਦਾ ਹੈ ਉਸਨੂੰ ਕਾਪੀ ਕਰੋ।
2. **ਤੁਹਾਡਾ ਅੰਕੀ Telegram ਯੂਜ਼ਰ ID** — [@userinfobot](https://t.me/userinfobot) ਨਾਲ ਗੱਲ ਕਰੋ ਅਤੇ ਜੋ ਨੰਬਰ ਉਹ ਦਿਖਾਉਂਦਾ ਹੈ ਉਸਨੂੰ ਕਾਪੀ ਕਰੋ। ਇਹ ਤੁਹਾਡਾ "ਬੌਸ" ID ਹੈ: ਸਿਰਫ਼ ਇਹ ਅਕਾਊਂਟ `/admin` ਵਰਤ ਸਕਦਾ ਹੈ।

## ਇੰਸਟਾਲ

ਇੱਕ ਕਮਾਂਡ। ਇਸ ਨੂੰ ਕਾਪੀ ਕਰੋ, ਆਪਣੇ ਟਰਮਿਨਲ ਵਿੱਚ ਪੇਸਟ ਕਰੋ, ਅਤੇ ਐਂਟਰ ਦਬਾਓ:

```bash
curl -sSL https://raw.githubusercontent.com/VortexLabsHQ/vortex-telegram-bot/main/install.sh | bash
```

ਇੰਸਟਾਲਰ ਤੁਹਾਨੂੰ ਕ੍ਰਮਵਾਰ ਛੇ ਸਵਾਲ ਪੁੱਛਦਾ ਹੈ:

1. **ਦੇਸ਼** — ਆਪਣੇ ਦੇਸ਼ ਦਾ ਅੰਗਰੇਜ਼ੀ ਨਾਮ **ਬਿਲਕੁਲ ਉਹੀ ਤਰ੍ਹਾਂ ਪੇਸਟ ਕਰੋ ਜਿਵੇਂ ਕਿ ਹੇਠਾਂ ਦਿੱਤੇ [ਦੇਸ਼ ਟੇਬਲ](#countries) ਵਿੱਚ ਲਿਸਟ ਕੀਤਾ ਗਿਆ ਹੈ** (ਉਦਾਹਰਣ ਲਈ `Turkey`)। ਦੇਸ਼ ਸਮੇਂ ਖੇਤਰ, ਮੁੱਲਾਂ ਲਈ ਸਥਾਨਕ ਕਰੰਸੀ, ਨਿਮਾਜ਼ ਦੇ ਸਮੇਂ, ਅਤੇ ਸਥਾਨਕ ਸਮੱਗਰੀ ਨੂੰ ਸੈੱਟ ਕਰਦਾ ਹੈ।
2. **ਭਾਸ਼ਾ** — ਵੋ ਭਾਸ਼ਾ ਜੋ ਬੋਟ ਬੋਲਦਾ ਹੈ (ਉਦਾਹਰਣ ਲਈ `en`, `fa`, `tr`)। ਆਪਣੇ ਦੇਸ਼ ਲਈ ਡਿਫਾਲਟ ਨੂੰ ਸਵੀਕਾਰ ਕਰਨ ਲਈ ਐਂਟਰ ਦਬਾਓ। ਭਾਸ਼ਾ ਦੇਸ਼ ਤੋਂ ਵੱਖਰੀ ਹੈ: ਇਹ ਸਿਰਫ਼ ਬਦਲਦੀ ਹੈ ਕਿ ਬੋਟ ਕੀ ਕਹਿੰਦਾ ਹੈ, ਅਤੇ ਤੁਸੀਂ ਇਸ ਨੂੰ ਬਾਅਦ ਵਿੱਚ `/admin` ਤੋਂ ਬਦਲ ਸਕਦੇ ਹੋ।
3. **ਬੋਟ ਟੋਕਨ** — [@BotFather](https://t.me/BotFather) ਤੋਂ ਟੋਕਨ ਪੇਸਟ ਕਰੋ। ਇੰਸਟਾਲਰ ਇਸ ਨੂੰ ਟੈਲੀਗ੍ਰਾਮ ਨਾਲ ਲਾਈਵ ਚੈੱਕ ਕਰਦਾ ਹੈ।
4. **ਬੌਸ ਨਮੇਰਿਕ ਆਈਡੀ** — [@userinfobot](https://t.me/userinfobot) ਤੋਂ ਤੁਹਾਡਾ ਟੈਲੀਗ੍ਰਾਮ ਯੂਜ਼ਰ ਆਈਡੀ।
5. **ਬੋਟ ਦਾ ਨਾਮ / ਵੇਕ ਵਰਡ** — ਵਹ ਨਾਮ ਜੋ ਲੋਕ ਗਰੁੱਪਾਂ ਵਿੱਚ ਬੋਟ ਨਾਲ ਗੱਲਬਾਤ ਕਰਨ ਲਈ ਕਹਿੰਦੇ ਹਨ। ਕੋਈ ਵੀ ਭਾਸ਼ਾ ਠੀਕ ਹੈ (ਉਦਾਹਰਣ ਲਈ `Vortex` ਜਾਂ `ورتکس`)। ਡਿਫਾਲਟ `Vortex` ਲਈ ਐਂਟਰ ਦਬਾਓ।
6. **ਪਹਿਲਾ LLM ਪ੍ਰੋਵਾਈਡਰ** — ਇੱਕ ਚੁਣੋ: OpenAI, Anthropic, OpenRouter, Google AI (Gemini), DeepSeek, Groq, Together AI, Mistral AI, xAI (Grok), Cohere, ਜਾਂ **ਕਸਟਮ** (ਬੇਸ URL ਪੇਸਟ ਕਰੋ)। ਫਿਰ ਉਸ ਪ੍ਰੋਵਾਈਡਰ ਲਈ ਆਪਣੀ API ਕੀ ਪੇਸਟ ਕਰੋ — ਇੰਸਟਾਲਰ ਪ੍ਰੋਵਾਈਡਰ ਦੀ ਲਾਈਵ ਮਾਡਲ ਸੂਚੀ ਲਿਆਉਂਦਾ ਹੈ ਅਤੇ ਤੁਸੀਂ ਇੱਕ ਮਾਡਲ ਚੁਣਦੇ ਹੋ।

ਫਿਰ ਇੰਸਟਾਲਰ ਨਿਰਭਰਤਾਵਾਂ ਨੂੰ ਇੰਸਟਾਲ ਕਰਦਾ ਹੈ, `.env` ਫਾਈਲ ਲਿਖਦਾ ਹੈ, `vortex-bot` systemd ਸਰਵਿਸ ਬਣਾਉਂਦਾ ਹੈ, ਵੈੱਬ ਖੋਜ ਲਈ SearXNG ਇੰਸਟਾਲ ਕਰਨ ਦੀ ਪੇਸ਼ਕਸ਼ ਕਰਦਾ ਹੈ (ਡਾਕਰ ਦੀ ਲੋੜ ਹੈ), ਅਤੇ ਬੋਟ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ।

> ⚠️ **Anthropic ਸਿੱਧੇ ਕੰਮ ਨਹੀਂ ਕਰਦਾ।** Anthropic ਦਾ ਦੇਸ਼ੀ API OpenAI-ਅਨੁਕੂਲ ਨਹੀਂ ਹੈ, ਅਤੇ ਇਹ ਬੋਟ ਸਿਰਫ਼ OpenAI-ਅਨੁਕੂਲ API ਬੋਲਦਾ ਹੈ। ਜੇ ਤੁਸੀਂ Anthropic ਚੁਣਦੇ ਹੋ, ਤਾਂ ਇੰਸਟਾਲਰ ਤੁਹਾਨੂੰ ਚੇਤਾਵਨੀ ਦਿੰਦਾ ਹੈ: ਕੀ ਸਿਰਫ਼ OpenAI-ਅਨੁਕੂਲ ਗੇਟਵੇ ਰਾਹੀਂ ਕੰਮ ਕਰਦੀ ਹੈ। ਬਜਾਏ OpenRouter, ਜਾਂ ਸੂਚੀ ਵਿੱਚੋਂ ਕੋਈ ਹੋਰ ਪ੍ਰੋਵਾਈਡਰ ਵਰਤੋ।

## ਇੰਸਟਾਲ ਕਰਨ ਤੋਂ ਬਾਅਦ

ਜਾਂਚੋ ਕਿ ਬੋਟ ਚੱਲ ਰਿਹਾ ਹੈ:

```bash
systemctl status vortex-bot
```

ਤੁਹਾਨੂੰ `active (running)` ਦਿਖਣਾ ਚਾਹੀਦਾ ਹੈ। ਲਾਈਵ ਲੌਗ ਦੇਖਣ ਲਈ:

```bash
journalctl -u vortex-bot -f
```

ਹੁਣ ਟੈਲੀਗ੍ਰਾਮ ਖੋਲ੍ਹੋ ਅਤੇ ਆਪਣੇ ਬੋਟ ਨਾਲ ਗੱਲ ਕਰੋ:

- `/start` ਭੇਜੋ — ਬੋਟ ਹੈਲੋ ਕਹੇਗਾ।

**ਅਪਡੇਟ ਆਪਣੇ ਆਪ ਹੁੰਦੇ ਹਨ।** ਦਿਨ ਵਿੱਚ ਇੱਕ ਵਾਰ ਬੋਟ GitHub 'ਤੇ ਨਵੇਂ ਰਿਲੀਜ਼ ਦੀ ਜਾਂਚ ਕਰਦਾ ਹੈ। ਜੇ ਉਪਲਬਧ ਹੈ, ਤਾਂ ਇਹ ਤੁਹਾਨੂੰ ✅ / ❌ ਬਟਨਾਂ ਨਾਲ ਇੱਕ ਨਿੱਜੀ ਸੁਨੇਹਾ ਭੇਜਦਾ ਹੈ। ✅ ਦਬਾਓ ਅਤੇ ਇਹ ਆਪਣੇ ਆਪ ਅਪਡੇਟ ਹੋ ਕੇ ਰੀਸਟਾਰਟ ਹੋ ਜਾਂਦਾ ਹੈ — ਤੁਹਾਨੂੰ ਕਦੇ ਸਰਵਰ ਨੂੰ ਛੂਣ ਦੀ ਲੋੜ ਨਹੀਂ ਪੈਂਦੀ।

## ਕੌਂਫ਼ਿਗਰੇਸ਼ਨ

ਸਾਰੀਆਂ ਸੈਟਿੰਗਜ਼ ਇੰਸਟਾਲ ਡਾਇਰੈਕਟਰੀ ਵਿੱਚ `.env` ਫਾਈਲ ਵਿੱਚ ਰਹਿੰਦੀਆਂ ਹਨ। ਹਰ ਵਿਕਲਪ ਲਈ [`.env.example`](.env.example) ਵੇਖੋ। ਸਭ ਤੋਂ ਮਹੱਤਵਪੂਰਨ ਵੋ:

| ਸੈਟਿੰਗ | ਇਹ ਕੀ ਕਰਦਾ ਹੈ |
| --- | --- |
| `BOT_TOKEN` | ਤੁਹਾਡਾ ਟੈਲੀਗ੍ਰਾਮ ਬੋਟ ਟੋਕਨ (@BotFather ਤੋਂ) |
| `BOSS_ID` | ਤੁਹਾਡਾ ਅੰਕੀ ਟੈਲੀਗ੍ਰਾਮ ਯੂਜ਼ਰ ਆਈਡੀ (ਬੋਟ ਮਾਲਕ) |
| `BOT_NAME` | ਬੋਟ ਦਾ ਨਾਮ ਅਤੇ ਵੇਕ ਵਰਡ ਗਰੁੱਪਾਂ ਵਿੱਚ (ਡਿਫ਼ਾਲਟ `Vortex`) |
| `BOT_COUNTRY` | ਦੇਸ਼ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ, ਜਿਵੇਂ `United States` (ਟਾਈਮ ਜ਼ੋਨ, ਕਰੰਸੀ, ਨਿਮਾਜ਼ ਦੇ ਸਮਾਂ ਸੈਟ ਕਰਦਾ ਹੈ) |
| `BOT_LANGUAGE` | ਬੋਟ ਭਾਸ਼ਾ ਕੋਡ, ਜਿਵੇਂ `en`, `fa`, `tr` (ਸਿਰਫ਼ ਬੋਟ ਕੀ ਕਹਿੰਦਾ ਹੈ ਉਹ ਬਦਲਦਾ ਹੈ) |
| `LLM_PROVIDERS` | LLM ਪ੍ਰੋਵਾਈਡਰ ਅਤੇ ਕੀਜ਼: `base_url\|api_key\|model`, ਕੋਮਾ-ਵੱਖਰੇ |
| `UPDATE_CHECK_ENABLED` | `1` = ਰੋਜ਼ਾਨਾ ਅਪਡੇਟ ਚੈੱਕ ਕਰੋ, `0` = ਕਦੇ ਨਹੀਂ ਚੈੱਕ ਕਰੋ |
| `UPDATE_REPO` | ਵੋ ਰਿਪੋ ਜਿਸਦੇ ਰਿਲੀਜ਼ ਵੇਖੇ ਜਾਂਦੇ ਹਨ (ਡਿਫ਼ਾਲਟ `VortexLabsHQ/vortex-telegram-bot`) |
| `SEARCH_PROVIDER` | ਵੈੱਬ ਖੋਜ: `searxng` (ਡਿਫ਼ਾਲਟ), `tavily`, ਜਾਂ `serper` |
| `DAILY_LIMIT_MESSAGES` | ਪ੍ਰਤੀ ਯੂਜ਼ਰ ਪ੍ਰਤੀ ਦਿਨ ਬੋਟ ਦੇ ਜਵਾਬਾਂ ਦੀ ਹੱਦ (ਡਿਫ਼ਾਲਟ `30`, ਬੌਸ ਨੂੰ ਛੂਟ ਹੈ) |

ਦੇਸ਼ ਅਤੇ ਭਾਸ਼ਾ ਨੂੰ ਬਾਅਦ ਵਿੱਚ ਲੁਕੇ ਹੋਏ `/admin` ਪੈਨਲ (ਭਾਸ਼ਾ ਅਤੇ ਦੇਸ਼) ਤੋਂ ਵੀ ਬਦਲਿਆ ਜਾ ਸਕਦਾ ਹੈ, ਬਿਨਾਂ ਕਿਸੇ ਫਾਈਲ ਨੂੰ ਸੰਪਾਦਿਤ ਕੀਤੇ।

## Docker ਵਿਕਲਪ

ਜੇਕਰ ਤੁਸੀਂ ਇੰਸਟਾਲਰ ਦੀ ਬਜਾਏ Docker ਨੂੰ ਤਰਜੀਹ ਦਿੰਦੇ ਹੋ:

```bash
cp .env.example .env   # fill in BOT_TOKEN, BOSS_ID, and your LLM key(s)
docker compose up -d --build
```

ਇਹ ਬੋਟ ਨੂੰ ਇੱਕ ਸਵੈ-ਹੋਸਟ ਕੀਤੇ ਗਏ SearXNG ਸਰਚ ਇੰਜਨ ਨਾਲ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ। `docker compose logs -f bot` ਨਾਲ ਲਾਗਾਂ ਚੈੱਕ ਕਰੋ।

ਨੋਟ: ਆਟੋਮੈਟਿਕ ਸੈਲਫ-ਅਪਡੇਟਰ ਨੂੰ systemd ਸਰਵਿਸ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ, ਇਸ ਲਈ Docker ਵਿੱਚ ਅਪਡੇਟ ਮੈਨੁਅਲ ਹਨ: `git pull` ਅਤੇ ਫਿਰ `docker compose up -d --build` ਦੁਬਾਰਾ।

ਤਸਵੀਰ ਜਨਰੇਸ਼ਨ ਤੁਹਾਡੀ ਆਪਣੀ OpenAI-ਅਨੁਕੂਲ ਇਮੇਜ ਸਰਵਿਸ ਦੀ ਵਰਤੋਂ ਕਰਦੀ ਹੈ: ਇਸਦਾ ਬੇਸ URL, API ਕੁੰਜੀ ਅਤੇ ਮਾਡਲ `/admin` ਵਿੱਚ ਸ਼ਾਮਲ ਕਰੋ (🖼️ ਇਮੇਜ ਮਾਡਲ)। ਕੋਈ ਬਿਲਟ-ਇਨ ਇਮੇਜ ਪ੍ਰੋਵਾਈਡਰ ਨਹੀਂ ਹੈ, ਅਤੇ ਫੋਟੋ ਸੰਪਾਦਨ ਸਮਰਥਿਤ ਨਹੀਂ ਹੈ। ਤਸਵੀਰ ਜਨਰੇਸ਼ਨ `/admin` ਤੋਂ ਬੰਦ ਕੀਤੀ ਜਾ ਸਕਦੀ ਹੈ।

## ਸਮੱਸਿਆ ਹੱਲ / ਅਕਸਰ ਪੁੱਛੇ ਜਾਂਦੇ ਸਵਾਲ

ਚਾਰ ਚੀਜ਼ਾਂ ਚੈੱਕ ਕਰੋ: (1) ਗਰੁੱਪ ਪ੍ਰਾਈਵੇਸੀ ਬੰਦ ਹੋਣੀ ਚਾਹੀਦੀ ਹੈ — [@BotFather](https://t.me/BotFather) ਵਿੱਚ `/setprivacy` ਭੇਜੋ, ਆਪਣਾ ਬੋਟ ਚੁਣੋ, ਅਤੇ **Disable** ਚੁਣੋ; ਜੇਕਰ ਪ੍ਰਾਈਵੇਸੀ ਚਾਲੂ ਹੈ, ਤਾਂ ਬੋਟ ਗਰੁੱਪ ਸੁਨੇਹੇ ਬਿਲਕੁਲ ਨਹੀਂ ਦੇਖ ਸਕਦਾ, (2) ਬੋਟ ਨੂੰ ਗਰੁੱਪ ਵਿੱਚ ਸ਼ਾਮਲ ਕੀਤਾ ਜਾਣਾ ਚਾਹੀਦਾ ਹੈ, (3) ਤੁਹਾਨੂੰ ਉਸਦਾ ਵੇਕ ਵਰਡ ਬੋਲਣਾ ਪਵੇਗਾ — ਉਸਦਾ ਨਾਮ, ਉਦਾਹਰਣ ਲਈ `Vortex what's the time?` — ਬੋਟ ਸਿਰਫ਼ ਤਬ ਸੁਣਦਾ ਹੈ ਜਦੋਂ ਗਰੁੱਪਾਂ ਵਿੱਚ ਉਸਦਾ ਨਾਮ ਲਿਆ ਜਾਂਦਾ ਹੈ, (4) ਨਿੱਜੀ ਚੈਟ ਵਿੱਚ ਕੋਈ ਵੇਕ ਵਰਡ ਲੋੜੀਂਦਾ ਨਹੀਂ।

**ਬਾਟ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਜਵਾਬ ਦਿੰਦਾ ਹੈ, ਮੇਰੀ ਭਾਸ਼ਾ ਵਿੱਚ ਨਹੀਂ।**
`/admin` ਭੇਜੋ (ਸਿਰਫ਼ ਬੌਸ) → ਭਾਸ਼ਾ ਅਤੇ ਦੇਸ਼, ਅਤੇ ਆਪਣੀ ਭਾਸ਼ਾ ਚੁਣੋ। ਇੰਸਟਾਲਰ ਵੀ ਭਾਸ਼ਾ ਪੁੱਛਦਾ ਹੈ — ਉੱਥੇ Enter ਦਬਾਓ ਆਪਣੇ ਦੇਸ਼ ਦੀ ਡਿਫਾਲਟ ਭਾਸ਼ਾ ਮਨਜ਼ੂਰ ਕਰਨ ਲਈ।

**ਮੈਂ Anthropic ਚੁਣਿਆ ਅਤੇ ਬਾਟ ਚੈਟ ਨਹੀਂ ਕਰਦਾ।**
Anthropic ਦਾ ਨੇਟਿਵ API OpenAI-ਸੰਗਤ ਨਹੀਂ ਹੈ, ਇਸ ਲਈ ਬਾਟ ਸਿੱਧੇ ਇਸ ਨਾਲ ਚੈਟ ਨਹੀਂ ਕਰ ਸਕਦਾ। OpenRouter ਵਰਤੋ (ਜੋ OpenAI-ਸੰਗਤ API ਰਾਹੀਂ Claude ਮਾਡਲ ਪ੍ਰਦਾਨ ਕਰ ਸਕਦਾ ਹੈ), ਜਾਂ ਸੂਚੀ ਤੋਂ ਕੋਈ ਹੋਰ ਪ੍ਰੋਵਾਈਡਰ ਚੁਣੋ।

**ਵੈਬ ਖੋਜ ਕੰਮ ਨਹੀਂ ਕਰਦੀ।**
ਵੈਬ ਖੋਜ ਨੂੰ SearXNG ਦੀ ਲੋੜ ਹੈ, ਜਿਸਨੂੰ ਇੰਸਟਾਲਰ Docker ਨਾਲ ਸੈਟਅਪ ਕਰਨ ਦੀ ਪੇਸ਼ਕਸ਼ ਕਰਦਾ ਹੈ। ਇਸ ਦੇ ਬਿਨਾਂ, ਬਾਟ Wikipedia 'ਤੇ ਵਾਪਸ ਆ ਜਾਂਦਾ ਹੈ, ਜੋ ਕਮਜ਼ੋਰ ਹੈ। ਤੁਸੀਂ `.env` ਵਿੱਚ `SEARCH_API_KEY` ਨਾਲ `SEARCH_PROVIDER=tavily` ਜਾਂ `serper` ਵੀ ਸੈਟ ਕਰ ਸਕਦੇ ਹੋ।

**ਲੌਗ ਕਿੱਥੇ ਹਨ?**
`journalctl -u vortex-bot -f` ਲਾਈਵ ਲੌਗ ਦਿਖਾਉਂਦਾ ਹੈ। `systemctl status vortex-bot` ਦਿਖਾਉਂਦਾ ਹੈ ਕਿ ਸਰਵਿਸ ਚੱਲ ਰਿਹਾ ਹੈ ਜਾਂ ਨਹੀਂ। ਜੇਕਰ ਬਾਟ ਰੁਕ ਜਾਂਦਾ ਹੈ, `sudo systemctl restart vortex-bot` ਇਸਨੂੰ ਦੁਬਾਰਾ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ।

**ਬਾਟ ਕਹਿੰਦਾ ਹੈ ਕਿ ਮੈਂ ਦਿਨਾਂਕ ਹੱਦ ਪਹੁੰਚ ਗਿਆ ਹਾਂ।**
ਹਰ ਯੂਜ਼ਰ ਨੂੰ ਪ੍ਰਤੀ ਦਿਨ 30 ਬਾਟ ਜਵਾਬ ਮਿਲਦੇ ਹਨ (ਬੌਸ ਨੂੰ ਛੂਟ ਹੈ)। ਹੱਦ ਬਾਟ ਦੇ ਦੇਸ਼ ਦੇ ਸਮੇਂ ਖੇਤਰ ਵਿੱਚ ਅੱਧੀ ਰਾਤ ਨੂੰ ਰੀਸੈਟ ਹੁੰਦੀ ਹੈ। ਇਸਨੂੰ `.env` ਵਿੱਚ `DAILY_LIMIT_MESSAGES` ਨਾਲ ਵਧਾਓ, ਜਾਂ ਬੌਸ ਤੋਂ ਪੁੱਛੋ।

**ਮੈਨੂੰ ਬੱਗ ਮਿਲਿਆ / ਮੇਰੇ ਕੋਲ ਇੱਕ ਵਿਚਾਰ ਹੈ।**
ਕਿਰਪਾ ਕਰਕੇ GitHub 'ਤੇ ਇੱਕ issue ਖੋਲ੍ਹੋ — [CONTRIBUTING.md](CONTRIBUTING.md) ਵੇਖੋ ਕਿ ਇਸਨੂੰ ਕਿਵੇਂ ਰਿਪੋਰਟ ਕਰਨਾ ਹੈ ਅਤੇ ਕਿਵੇਂ ਫਿਕਸ ਭੇਜਣਾ ਹੈ।

## ਵਿਕਾਸ

```bash
git clone https://github.com/VortexLabsHQ/vortex-telegram-bot.git
cd vortex-telegram-bot

python3.11 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
pip install ruff

cp .env.example .env   # then fill in your own BOT_TOKEN and LLM key(s)
python -m bot.main
```

ਟੈਸਟ ਚਲਾਓ (ਸਾਦੇ Python ਸਕ੍ਰਿਪਟ, pytest ਦੀ ਲੋੜ ਨਹੀਂ):

```bash
python tests/test_admin.py
python tests/test_admin_keys.py
python tests/test_admin_select.py
python tests/test_admin_power.py
python tests/test_admin_image.py
python tests/test_fixes.py
python tests/test_installer.py
python tests/test_locale.py
python tests/test_updater.py
```

ਸਾਰੇ ਨੌ ਸੂਟ ਪਾਸ ਹੋਣੇ ਚਾਹੀਦੇ ਹਨ ਪੁਲ ਰਿਕਵੈਸਟ ਖੋਲ੍ਹਣ ਤੋਂ ਪਹਿਲਾਂ। ਕੋਡ ਸਟਾਈਲ (ruff) ਅਤੇ PR ਪ੍ਰਕਿਰਿਆ ਲਈ [CONTRIBUTING.md](CONTRIBUTING.md) ਵੇਖੋ।
