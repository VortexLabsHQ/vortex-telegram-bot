## Vortex શું છે?

Vortex એ Telegram બોટ છે જે તમારા ગ્રુપ્સ અને નિજી ચેટ્સમાં રહે છે અને AI ચેટ મોડેલ સાથે લોકોને જવાબ આપે છે. તમે તેનું નામ લો (ડિફોલ્ટ નામ **Vortex** છે) અને તે જવાબ આપે છે — તે ચેટ કરી શકે છે, વેબ શોધી શકે છે, ચિત્ર બનાવી શકે છે, કિંમતો તપાસી શકે છે, જોક્સ સુનાવી શકે છે, ફાઈલો વાંચી શકે છે, વૉઈસ મેસેજ ટ્રાન્સ્ક્રાઇબ કરી શકે છે, અને વધુ.

તે તમારા પોતાના સર્વર પર, તમારા પોતાના દેશ અને ભાષામાં ચલે છે. તમે બૉસ છો: એક છુપાયેલ `/admin` પેનેલ તમને AI કી, યુઝર્સ, અને સેટિંગ્સ મેનેજ કરવા દે છે.

## સુવિધાઓ

- 💬 **AI ચેટ** ગ્રુપ્સમાં (વેક અર્થ) અને નિજી ચેટ્સમાં (વેક અર્થની જરૂર નથી)
- 🔑 **ટોકન પૂલ** — ઘણા LLM પ્રોવાઇડર્સ અને કીનો ઉપયોગ કરો, આપોઆપ રોટેટ અને ફેલઓવર કરો
- 🖼️ **ચિત્ર જનરેશન અને એડિટિંગ** — મફત (DuckAI) અથવા પેડ પ્રોવાઇડર્સ
- 🔍 **વેબ શોધ** — સેલ્ફ-હોસ્ટેડ SearXNG, વિકિપીડિયા ફોલબેક સાથે
- 💰 **લાઈવ કિંમતો** — મુદ્રાઓ, સોનું, તેલ, અને ક્રિપ્ટો તમારા સ્થાનિક મુદ્રામાં
- 🕌 **નમાજના સમય**, 🃏 **ભાગ્ય**, 😄 **જોક્સ**, 🎲 **પાંસા અને સિક્કા ઉછાળવા**
- 📎 **ફાઈલ વિશ્લેષણ** અને **વૉઈસ ટ્રાન્સ્ક્રિપ્શન**
- 📥 **ડાઉનલોડ્સ** — લિંક મોકલો, મીડિયા ફાઈલ પાછો મેળવો (45 MB સુધી)
- 🌍 **195 દેશો** અને **40 ભાષાઓ** — દેશ અને ભાષા અલગ સેટિંગ્સ છે
- 🔄 **સ્વયં-અપડેટિંગ** — દરરોજ નવા રિલીઝ તપાસે છે અને અપડેટ કરતા પહેલા પૂછે છે
- 🛡️ **છુપાયેલ /admin પેનેલ** — ટોકન્સ, યુઝર્સ, સ્ટાટ્સ, ચેટ્સ, ઇમેજ મોડેલ, મેનેજર્સ, પાવર

## ઇન્સ્ટોલ કરતા પહેલા

તમારને એક સર્વર (અથવા એક કમ્પ્યુટર جو ચાલુ રહે) જોઈએ જે **Linux** ચલાવે અને જેમાં આ ઇન્સ્ટોલ હોય:

| શું | કેવી રીતે તપાસવું | તમને શું જોઈએ |
| --- | --- | --- |
| **Python 3.11 અથવા નવીન** | `python3 --version` | `Python 3.11.x` અથવા વધુ (3.12 અને 3.13 પણ કામ કરે) |
| **git** | `git --version` | `git version 2.x.x` |
| **curl** | `curl --version` | `curl 7.x.x` અથવા `8.x.x` |
| **systemd** | `systemctl --version` | `systemd 24x` અથવા સરખું |
| **Docker** *(વૈકલ્પિક)* | `docker --version` | `Docker version 2x.x.x` — માત્ર જરૂરી છે જો તમને વૈકલ્પિક SearXNG વેબ શોધ જોઈએ |

જો કંઈક મિશિંગ હોય, તો ઇન્સ્ટોલર તેને `apt` સાથે તમારા માટે ઇન્સ્ટોલ કરવાની પેશકશ કરે છે (Debian/Ubuntu પર). અન્ય સિસ્ટમ્સ પર, પહેલા તમારા પેકેજ મેનેજર સાથે ઇન્સ્ટોલ કરો.

તમને Telegram થી બે વસ્તુઓની પણ જરૂર છે (બંને મફત છે):

1. **એક બોટ ટોકન** — Telegram પર [@BotFather](https://t.me/BotFather) સાથે બાત કરો, `/newbot` મોકલો, અને તે જે ટોકન આપે તે કૉપી કરો.
2. **તમારો આંકડાકીય Telegram યુઝર ID** — [@userinfobot](https://t.me/userinfobot) સાથે બાત કરો અને તે જે નંબર બતાવે તે કૉપી કરો. આ તમારો "બૉસ" ID છે: માત્ર આ એકાઉન્ટ `/admin` વાપરી શકે છે.

## ઇન્સ્ટોલ

એક કમાન્ડ. તે કૉપી કરો, તમારા ટર્મિનલમાં પેસ્ટ કરો, અને Enter દબાવો:

```bash
curl -sSL https://raw.githubusercontent.com/VortexLabsHQ/vortex-telegram-bot/main/install.sh | bash
```

ઇન્સ્ટોલર તમને ક્રમમાં છ સવાલો પૂછે છે:

1. **દેશ** — તમારા દેશનું અંગ્રેજી નામ ચિપકાવો **નીચેના [દેશ કોષ્ટક](#countries) માં જેવું લખ્યું છે તે જ** (ઉદાહરણ તરીકે `Turkey`)। દેશ સમય ક્ષેત્ર, કિંમતો માટે સ્થાનિક મુદ્રા, નમાઝના સમય, અને સ્થાનિક સામગ્રી નક્કી કરે છે।
2. **ભાષા** — બોટ જે ભાષા બોલે છે (ઉદાહરણ તરીકે `en`, `fa`, `tr`)। તમારા દેશ માટે ડિફોલ્ટ સ્વીકારવા માટે Enter દબાવો। ભાષા દેશથી અલગ છે: તે ફક્ત બોટ શું કહે છે તે બદલે છે, અને તમે પછીથી `/admin` થી બદલી શકો છો।
3. **બોટ ટોકન** — [@BotFather](https://t.me/BotFather) થી મળેલો ટોકન ચિપકાવો। ઇન્સ્ટોલર તેને Telegram સાથે લાઈવ તપાસે છે।
4. **બૉસ ન્યુમેરિક ID** — [@userinfobot](https://t.me/userinfobot) થી મળેલો તમારો Telegram યુઝર ID।
5. **બોટનું નામ / વેક અપ વર્ડ** — લોકો ગ્રૂપમાં બોટ સાથે બાત કરવા જે નામ કહે છે। કોઈ પણ ભાષા ચાલશે (ઉદાહરણ તરીકે `Vortex` અથવા `ورتکس`)। ડિફોલ્ટ `Vortex` માટે Enter દબાવો।
6. **પ્રથમ LLM પ્રોવાઇડર** — એક પસંદ કરો: OpenAI, Anthropic, OpenRouter, Google AI (Gemini), DeepSeek, Groq, Together AI, Mistral AI, xAI (Grok), Cohere, અથવા **Custom** (બેઝ URL ચિપકાવો)। પછી તે પ્રોવાઇડર માટે તમારો API કી ચિપકાવો — ઇન્સ્ટોલર પ્રોવાઇડરની લાઈવ મોડેલ યાદી લાવે છે અને તમે મોડેલ પસંદ કરો છો।

પછી ઇન્સ્ટોલર ડિપેન્ડન્સી ઇન્સ્ટોલ કરે છે, `.env` ફાઈલ લખે છે, `vortex-bot` systemd સર્વિસ બનાવે છે, વેબ સર્ચ માટે SearXNG ઇન્સ્ટોલ કરવાનો વિકલ્પ આપે છે (Docker જરૂરી છે), અને બોટ શરૂ કરે છે।

> ⚠️ **Anthropic સીધા કાર્ય કરતું નથી.** Anthropic નેટિવ API OpenAI-સંગત નથી, અને આ બોટ ફક્ત OpenAI-સંગત API બોલે છે. જો તમે Anthropic પસંદ કરો, તો ઇન્સ્ટોલર ચેતવણી આપે છે: કી ફક્ત OpenAI-સંગત ગેટવે દ્વારા કાર્ય કરશે. બદલે OpenRouter, અથવા યાદીમાંથી કોઈ બીજો પ્રોવાઇડર વાપરો.

## ઇન્સ્ટોલ કર્યા પછી

બોટ ચાલુ છે કે નહીં તે તપાસો:

```bash
systemctl status vortex-bot
```

તમને `active (running)` દેખાયું જોઈએ. લાઈવ લોગ જોવા માટે:

```bash
journalctl -u vortex-bot -f
```

હવે Telegram ખોલો અને તમારા બોટ સાથે બાત કરો:

- `/start` મોકલો — બોટ હેલો કહે છે.
- **નિજી ચેટ**માં, ફક્ત લખો — વેક વર્ડની જરૂર નથી.
- **ગ્રૂપ**માં, બોટને ગ્રૂપમાં ઉમેરો, પછી તેનું નામ કહો, ઉદાહરણ: `Vortex what's the time?`
- બૉસ તરીકે, નિજી ચેટમાં `/admin` મોકલો છુપા એડમિન પેનલ ખોલવા માટે.

**અપડેટ્સ આપોઆપ થાય છે.** દરરોજ બોટ GitHub પર નવું રિલીઝ તપાસે છે. જો ઉપલબ્ધ હોય, તો તે તમને ✅ / ❌ બટન સાથે નિજી સંદેશ મોકલે છે. ✅ ટેપ કરો અને તે પોતે અપડેટ થઈને પુનઃશરૂ થાય — તમને કદાચ સર્વરને સ્પર્શ કરવાની જરૂર ન પડે.

## કોન્ફિગરેશન

બધી સેટિંગ્સ ઇન્સ્ટોલ ડિરેક્ટરીમાં `.env` ફાઈલમાં છે. દરેક વિકલ્પ માટે [`.env.example`](.env.example) જુઓ. સૌથી મહત્વપૂર્ણો:

| Setting | તે શું કરે છે |
| --- | --- |
| `BOT_TOKEN` | તમારો Telegram બોટ ટોકન (@BotFather થી) |
| `BOSS_ID` | તમારો આંકડાકીય Telegram યુઝર ID (બોટ માલિક) |
| `BOT_NAME` | બોટનું નામ અને ગ્રૂપ્સમાં જાગૃત શબ્દ (ડિફોલ્ટ `Vortex`) |
| `BOT_COUNTRY` | દેશ અંગ્રેજીમાં, જેમ કે `United States` (સમય ક્ષેત્ર, મુદ્રા, નમાઝનો સમય સેટ કરે છે) |
| `BOT_LANGUAGE` | બોટ ભાષા કોડ, જેમ કે `en`, `fa`, `tr` (ફક્ત બોટ શું કહે છે તે બદલે છે) |
| `LLM_PROVIDERS` | LLM પ્રોવાઇડર્સ અને કીઝ: `base_url\|api_key\|model`, કોમા-વિભાજિત |
| `UPDATE_CHECK_ENABLED` | `1` = દૈનિક અપડેટ તપાસો, `0` = કદાચ નહીં તપાસો |
| `UPDATE_REPO` | જਿਸ રિપોના રિલીઝ પર નિગરાની રાખવામાં આવે છે (ડિફોલ્ટ `VortexLabsHQ/vortex-telegram-bot`) |
| `SEARCH_PROVIDER` | વેબ સર્ચ: `searxng` (ડિફોલ્ટ), `tavily`, અથવા `serper` |
| `DAILY_LIMIT_MESSAGES` | પ્રતિ યુઝર પ્રતિ દિવસ મેક્સ બોટ જવાબ (ડિફોલ્ટ `30`, બૉસ મુક્ત છે) |

દેશ અને ભાષા બાદમાં લુકાયેલા `/admin` પેનલથી (ભાષા અને દેશ) પણ બદલી શકાય છે, કોઈ ફાઈલ સંપાદન કર્યા વગર.

## Docker વિકલ્પ

જો તમે ઇન્સ્ટોલર કરતાં Docker પસંદ કરો:

```bash
cp .env.example .env   # fill in BOT_TOKEN, BOSS_ID, and your LLM key(s)
docker compose up -d --build
```

આ બોટને સ્વયં-হોસ્ટેડ SearXNG સર્ચ એન્જિન સાથે શરૂ કરે છે. લોગ્સ તપાસો `docker compose logs -f bot` સાથે.

નોંધ: સ્વચાલિત સ્વયં-અપડેટરને systemd સર્વિસની જરૂર પડે છે, તેથી Docker-માં અપડેટ્સ મેન્યુઅલ છે: `git pull` અને પછી ફરીથી `docker compose up -d --build`.

## વિશેષતાઓ વિસ્તારથી

### /admin પેનલ

નિજી ચેટમાં `/admin` મોકલો (બૉસ માત્ર — કોઈ બીજો તે ખોલી શકતો નથી, અને તે `/help` અથવા મેનુમાં કદાચ દેખાય નથી). તેમાં છે:

- 🔑 **ટોકન્સ અને મોડેલ** — LLM કીઝ ઉમેરો અથવા દૂર કરો, જુઓ કે કौનસી કીઝ સ્વસ્થ છે, સક્રિય મોડેલ પસંદ કરો, પ્રોવાઇડરની લાઈવ મોડેલ યાદી બ્રાઉઝ કરો
- 👥 **યુઝર્સ** — યુઝર ગણતરી, બેન / আনબેન, એલોવલિસ્ટ
- 📊 **સ્ટેટ્સ** — ઉપયોગના આંકડા
- 💬 **નવીન ચેટ્સ** — લોકોએ બોટને શું કહ્યું (બૉસ માત્ર, નિજી)
- 🖼️ **ઇમેજ મોડેલ** — DuckAI (મફત, ડિફોલ્ટ), HiLinkUp, કસ્ટમ ઇમેજ સર્વિસ, અથવા બંધ
- 🛡️ **મેનેજર્સ** — વિશ્વસનીય લોકોને પેનલના ભાગોમાં પહોંચ આપો
- 🟢/🔴 **પાવર** — બોટને બધા માટે ચાલુ અથવા બંધ કરો (બૉસ નિયંત્રણમાં રહે છે)
- 🌍 **ભાષા અને દેશ** — બોટની ભાષા અથવા દેશ કોઈપણ સમય બદલો

### ટોકન પૂલ

બોટ એકસાથે કઈ સરખા LLM પ્રોવાઇડર્સની કીઝ ધરાવી શકે છે. તે સ્વસ્થ કીઝ વચ્ચે રોટેટ કરે છે અને જ્યારે એક બંધ પડે ત્યારે સ્વચાલિત રીતે ફેલઓવર કરે છે. `/admin` થી તમે એક મોડેલ પિન કરી શકો, હાથથી મોડેલ પસંદ કરી શકો, અથવા બોટને મુક્ત રોટેટ કરવા દી શકો. OpenAI-સંગત APIવાળો કોઈપણ પ્રોવાઇડર કામ કરે છે — જેમાં નાના એગ્રિગેટર્સ પણ શામેલ છે, ફક્ત મોટા નામો નહીં.

### ઇમેજ્સ

ઇમેજ જનરેશનના ત્રણ મોડ્સ છે: **DuckAI** (મફત, કોઈ કી નહીં, ડિફોલ્ટ), **HiLinkUp** (સશુલ્ક, સરસ ગુણવત્તા), અથવા તમારી પોતાની **કસ્ટમ** OpenAI-સંગત ઇમેજ સર્વિસ. તમે બોટને ફોટો પણ મોકલી શકો અને કહી શકો કે કેવી રીતે સંપાદન કરવું ("આને કાર્ટૂન સ્ટાઈલ બનાવ"), અને તે નવી ઇમેજ જનરેટ કરશે. ઇમેજ જનરેશન `/admin` થી બંધ કરી શકાય છે.

### દેશો અને ભાષાઓ

Vortex **195 દેશો** અને **40 ભાષાઓ**ને સમર્થન આપે છે. દેશ સમય ક્ષેત્ર, મુદ્રા જેમાં કિંમતો બતાવવામાં આવે છે, પ્રાર્થના સમય માટે શહેર, અને સ્થાનિક સામગ્રી નક્કી કરે છે. ભાષા માત્ર બોટ શું કહે છે તે નક્કી કરે છે — ઉદાહરણ તરીકે, બેલ્જિયમમાં એક ગ્રુપ દેશ બેલ્જિયમ અને ભાષા અંગ્રેજી વાપરી શકે છે. બંનેને પછીથી `/admin` થી બદલી શકાય છે.

### અપડેટ્સ

બોટ `VortexLabsHQ/vortex-telegram-bot` ના GitHub રિલીઝને દરરોજ એકવાર તપાસે છે. જ્યારે નવું સંસ્કરણ આવે છે, ત્યારે તે બૉસને ખાસ સંદેશ ✅ / ❌ બટનો સાથે મોકલે છે. સ્વીકાર કરવાથી કોડ અપડેટ થાય છે અને બોટ પુનઃશરૂ થાય છે. જ્યારે રિપો ખાનગી હોય, ત્યારે તપાસણી ચુપચાપ કંઈક નથી કરે (GitHub ની APIને જાહેર રિપો જોઈએ) — જો તમે ક્યારેય તપાસણી નाही ઈચ્છો તો `UPDATE_CHECK_ENABLED=0` સેટ કરો.

## સમસ્યા નિવારણ / FAQ

**ઇન્સ્ટોલર કહે છે કે મારો ટોકન અમાન્ય છે.**
ટોકન [@BotFather](https://t.me/BotFather) થી મળે છે. ખાતરી કરો કે તમે સંપૂર્ણ ટોકન કોપી કર્યું છે (અંક, એક કોલન, પછી 35+ અક્ષર), કોઈ વધારાની જગ્યા વગર. જો તમે બોટ મુક્યો હોય અથવા નવો ટોકન બનાવ્યો હોય, તો જૂનો કામ કરતો નથી — નવો પેસ્ટ કરો.

**બોટ મારા ગ્રુપમાં જવાબ નથી આપે.**
ત્રણ બાબતો તપાસવી: (1) બોટને ગ્રુપમાં ઉમેરવું પડે છે, (2) તમને તેનો વેક અપ શબ્દ કહેવો પડે છે — તેનું નામ, ઉદાહરણ તરીકે `Vortex what's the time?` — બોટ ગ્રુપોમાં તभी સુને છે જ્યારે તેનું નામ લેવાય છે, (3) ખાનગી ચેટમાં કોઈ વેક અપ શબ્દ જોઈએ નથી.

**બોટ અંગ્રેજીમાં જવાબ આપે છે, મારી ભાષામાં નહીં.**
`/admin` મોકલો (બૉસ માત્ર) → ભાષા અને દેશ, અને તમારી ભાષા પસંદ કરો. ઇન્સ્ટોલર પણ ભાષા પૂછે છે — તમારા દેશની ડિફોલ્ટ સ્વીકારવા માટે એન્ટર દબાવો.

**મેં Anthropic પસંદ કર્યું અને બોટ ચેટ નથી કરે.**
Anthropic ની મૂળ API OpenAI-સંગત નથી, તેથી બોટ સીધા તે સાથે ચેટ નથી કરી શકે. OpenRouter વાપરો (જે Claude મોડલ્સને OpenAI-સંગત API દ્વારા સેવા આપી શકે છે), અથવા યાદીમાંથી બીજો પ્રોવાઇડર પસંદ કરો.

**વેબ સર્ચ કામ નથી કરે.**
વેબ સર્ચને SearXNG જોઈએ છે, જે ઇન્સ્ટોલર Docker સાથે સેટ અપ કરવા ઓફર કરે છે. તે વગર, બોટ વિકિપીડિયા પર પડે છે, જે નબળું છે. તમે `.env` માં `SEARCH_PROVIDER=tavily` અથવા `serper` સાથે `SEARCH_API_KEY` પણ સેટ કરી શકો છો.

**લોગ્સ ક્યાં છે?**
`journalctl -u vortex-bot -f` લાઈવ લોગ બતાવે છે. `systemctl status vortex-bot` બતાવે છે કે સર્વિસ ચાલુ છે કે નહીં. જો બોટ બંધ પડે, તો `sudo systemctl restart vortex-bot` તેને ફરીથી શરૂ કરે છે.

**બોટ કહે છે કે હું દરરોજની મર્યાદા પહોંચી ગયો છું.**
દરેક વપરાશકર્તાને દરરોજ 30 બોટ જવાબ મળે છે (બૉસને છૂટ છે). મર્યાદા બોટના દેશના સમય ક્ષેત્ર મુજબ અર્ધરાત્રે રીસેટ થાય છે. `.env` માં `DAILY_LIMIT_MESSAGES` સાથે વધારો, અથવા બૉસને પૂછો.

**મને બગ મળ્યો / મારો વિચાર છે.**
કૃપા કરીને GitHub પર ઇશ્યુ ખોલો — કેવી રીતે રિપોર્ટ કરવું અને ફિક્સ કેવી રીતે મોકલવું તે માટે [CONTRIBUTING.md](CONTRIBUTING.md) જુઓ.

## વિકાસ

```bash
git clone https://github.com/VortexLabsHQ/vortex-telegram-bot.git
cd vortex-telegram-bot

python3.11 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
pip install ruff

cp .env.example .env   # then fill in your own BOT_TOKEN and LLM key(s)
python -m bot.main
```
