## Vortex ምንድን ነው?

Vortex በቡድኖቻችሁ እና በግል ንግግሮች ውስጥ የሚኖር የ Telegram ቦት ነው የሚሰጥ ሰዎችን በ AI የንግግር ሞዴል። ስሙን (የተለየ ስም **Vortex** ነው) በማለት ይመልሳል — ሊያደርግ የሚችለው መናገር፣ የድርጅትን መፈለግ፣ ምስሎችን ማድረግ፣ ዋጋዎችን ማረጋገጥ፣ ጥበቃዎችን ማስታወቅ፣ ፋይሎችን ማንበብ፣ የድምፅ መልእክቶችን ማስተርጎም እና ተጨማሪ ነው።

ይህ በእርስዎ ራስ ሰርቨር፣ በእርስዎ ራስ አገር እና ቋንቋ ላይ ይሰራል። እርስዎ ዋና አስተዳደር ነዎት፡ የተሰወረ የ `/admin` ፓነል AI ቁልፎች፣ ተጠቃሚዎች እና ቅንብሮችን ማስተዳደርን ያስችላል።

## ከማስገባት በፊት

የሚሰራ **Linux** ሰርቨር (ወይም የተጠበቀ ኮምፒውተር) አለብዎት ከሚከተለው ጋር የተጫነው:

| ምን | እንዴት ማረጋገጥ | የሚታዩት ምን |
| --- | --- | --- |
| **Python 3.11 ወይም ከዚያ የሚበርታ** | `python3 --version` | `Python 3.11.x` ወይም ከዚያ የሚበርታ (3.12 እና 3.13 ደግሞ ይሰራሉ) |
| **git** | `git --version` | `git version 2.x.x` |
| **curl** | `curl --version` | `curl 7.x.x` ወይም `8.x.x` |
| **systemd** | `systemctl --version` | `systemd 24x` ወይም ተመሳሳይ |
| **Docker** *(አማራጭ)* | `docker --version` | `Docker version 2x.x.x` — የአማራጭውን SearXNG የድርጅት ፈለግ ከፈለጉ ብቻ ያስፈልጋል |

ካለው የለውን ካልተገኘ፣ በአንድ ትእዛዝ ሁሉንም አስገባ ( `Debian/Ubuntu` ):

```bash
sudo apt update && sudo apt install -y python3 python3-venv python3-pip git curl
```

ለአማራጭ `Docker` (የሚፈለገው `SearXNG` የድርጅት ፈርግ ማግኘት ሲፈልግ ብቻ):

```bash
sudo apt install -y docker.io
sudo systemctl enable --now docker
sudo usermod -aG docker $USER
```

የመጨረሻውን መስመር በኋላ፣ ውጣ እና ደግሞ ግባ (ወይም `docker` ትእዛዞችን `sudo` ጋር አስፈጽም)። የስርጭት ፕሮግራም ደግሞ በ `Debian/Ubuntu` ላይ `apt` ያለውን የሌለውን መሳሪያዎች ለማስገባት ያስችላል። በሌሎች ስርዓቶች ላይ፣ በመጀመሪያ የእርስዎን ፓኬጅ አስተዳደር አስገባቸው። `systemd` ከስርዓቱ ጋር ይመጣል — በተለይ ሊገባ አይችልም።

ከ Telegram ደግሞ ሁለት ነገሮች ያስፈልጋሉ (ሁለቱም ነፃ ናቸው)፡

1. **የቦት ቶክን** — በ Telegram ላይ [@BotFather](https://t.me/BotFather) ከዚያ ይናገሩ፣ `/newbot` ይላኩ፣ ያስጠይቅዎትን ቶክን ይህልጡ።
2. **የእርስዎ ቁጥር የ Telegram ተጠቃሚ ID** — [@userinfobot](https://t.me/userinfobot) ከዚያ ይናገሩ እና ያሳያልዎትን ቁጥር ይህልጡ። ይህ የእርስዎ "ባለቤት" ID ነው፡ ይህን መለያ ብቻ `/admin` መጠቀም ይችላል።

## ማስገባት

አንድ ትእዛዝ። ይህልጡ፣ በ ተርሚናልዎ ይስቀሩ፣ እና Enter ይጫኑ፡

```bash
curl -sSL https://raw.githubusercontent.com/VortexLabsHQ/vortex-telegram-bot/main/install.sh | bash
```

የማስገባት ፕሮግራም ስድስት ጥያቄዎችን በቅድምያ ይጠይቃል፡

1. **አገር** — የአገርዎን የእንግሊዝኛ ስም በታች ያለውን በ[የአገሮች ሰንደሪት](#countries) እንደተደረገ ትክክል ያስቀምጡ (ለምሳሌ `Turkey`)። አገሩ የሰዓት ክልል፣ የአካባቢ ገንዘብ፣ የጸሎት ሰዓቶች እና የአካባቢ ይዘትን ያደርጋል።
2. **ቋንቋ** — ቦቱ የሚናገረው ቋንቋ (ለምሳሌ `en`፣ `fa`፣ `tr`)። ለአገርዎ የተወሰነውን አማካይነት ለማግኘት Enter ይጫኑ። ቋንቋ ከአገር ጋር ያለው የተለየ ነው፡፡ የቦቱን የሚናገረውን ብቻ ያስቀየራል እና ከዚህ በኋላ ከ `/admin` ለውጥ ማድረግ ይቻላል።
3. **የቦት ቶክን** — ከ[@BotFather](https://t.me/BotFather) የተገኘውን ቶክን ያስቀምጡ። ማዘጋጃው በቀጥታ Telegram ጋር ያስተናግዳል።
4. **የቦስ ቁጥር ID** — ከ[@userinfobot](https://t.me/userinfobot) የተገኘው የTelegram የተጠቃሚ ID።
5. **የቦት ስም / የማስታወቂያ ቃል** — ሰዎች በቡድኖች ውስጥ ለመናገር የሚጠቀሙት ስም። ማንኛውም ቋንቋ እንደሚገባ ነው (ለምሳሌ `Vortex` ወይም `ورتکس`)። ለአማካይነቱ `Vortex` Enter ይጫኑ።
6. **የመጀመሪያ LLM አቅርቦት** — አንዱን ይምረጡ፡፡ OpenAI፣ Anthropic፣ OpenRouter፣ Google AI (Gemini)፣ DeepSeek፣ Groq፣ Together AI፣ Mistral AI፣ xAI (Grok)፣ Cohere፣ ወይም **Custom** (የመሠረት URL ያስቀምጡ)። ከዚያም ለዚያ አቅርቦት የAPI ቁልፍዎን ያስቀምጡ — ማዘጋጃው የአቅርቦቱን የሕይወት የሞዴሎች ዝርዝር ያጠናክራል እና ሞዴል ይምረጡ።

በኋላ ማዘጋጃው የተወሳኝ ፓኬጆችን ያደርጋል፣ `.env` ፋይልን ያስቀምጣል፣ `vortex-bot` systemd አገልግሎትን ያፅዳል፣ SearXNGን ለየውህ ፈላጊዎች ሊያደርግ ይወድቃል (Docker ያስፈልጋል) እና ቦቱን ያስጀምራል።

> ⚠️ **Anthropic በቀጥታ አይሰራም።** የAnthropic የተለየ API ከOpenAI ጋር አይገናኝም፣ እና ይህ ቦት ብቻ የOpenAI-ተገቢ APIsን ያናገራል። ከሆነ Anthropicን ተወስጠዋል፣ ማዘጋጃው ማሳወቂያውን ያስታውሳል፡፡ ቁልፉ ብቻ በአንደኛ የOpenAI-ተገቢ ገቢ ይሰራል። OpenRouterን፣ ወይም ከዝርዝሩ ሌላ አቅርቦትን ይጠቀሙ።

## ማዘጋጃ በኋላ

ቦቱ እየተሰራ እንደሚገኝ ይመልከቱ፡፡

```bash
systemctl status vortex-bot
```

እባክዎ `active (running)` የሚል ነገር ይመልከቱ። ለሕይወት ምዝገባ ለማየት፡፡

```bash
journalctl -u vortex-bot -f
```

## ውሎች

ሁሉም ቅንብሮች በማዘጋጃ ዳይሬክቶሪ ውስጥ ያለው `.env` ፋይል አሉ። ለሁሉም አማራጮች [`.env.example`](.env.example)ን ይመልከቱ። በጣም አስፈላጊዎቹ፡፡

| Setting | ምን ያደርጋል |
| --- | --- |
| `BOT_TOKEN` | የTelegram ቦት ቶክን (ከ@BotFather) |
| `BOSS_ID` | የእርስዎ ቁጥጥር Telegram የተጠቃሚ ID (የቦቱ ባለቤት) |
| `BOT_NAME` | የቦቱ ስም እና በቡድኖች ውስጥ የማስታወቂያ ቃል (ነፃ ሁኔታ `Vortex`) |
| `BOT_COUNTRY` | በእንግሊዝኛ ሀገር, ለምሳሌ `United States` (የሰዓት ክልል፣ ገንዘብ፣ የጸሎት ሰዓቶችን ያደርጋል) |
| `BOT_LANGUAGE` | የቦቱ ቋንቋ ኮድ፣ ለምሳሌ `en`፣ `fa`፣ `tr` (ቦቱ ምን ያስባል ብቻ ያቀይራል) |
| `LLM_PROVIDERS` | LLM አቅራቢዎች እና ቁልፎች፡ `base_url\|api_key\|model`፣ በኮማ የተለየ |
| `UPDATE_CHECK_ENABLED` | `1` = በዕለት ሁሉም ማዳመጫ ማረጋገጥ፣ `0` = አይፈልግም |
| `UPDATE_REPO` | ሪልስ የተሰጠውን ተከትሎ ያጠብቃል (ነፃ ሁኔታ `VortexLabsHQ/vortex-telegram-bot`) |
| `SEARCH_PROVIDER` | የወቅታዊ ፈልግ፡ `searxng` (ነፃ ሁኔታ)፣ `tavily`፣ ወይም `serper` |
| `DAILY_LIMIT_MESSAGES` | በቀን ሁሉም ላይ ለተጠቃሚ የሚፈቀደው የቦት ምላሾች (ነፃ ሁኔታ `30`፣ ቦስ ነፃ ነው) |

ሀገር እና ቋንቋ ከዚህ በኋላ ደግሞ ከደብቀል `/admin` ፓነል (ቋንቋ እና ሀገር) ይቀይራሉ፣ ምንም ፋይል ማስተካከል ያስፈልጋል።

## Docker አማካይነት

የሰውነት አስተካክል ከሆነ Docker እያስፈልጋላችሁ፡

```bash
cp .env.example .env   # fill in BOT_TOKEN, BOSS_ID, and your LLM key(s)
docker compose up -d --build
```

ይህ ቦቱን ጋር የተለያዩ የራሱን SearXNG ፈልግ ማስኬድያ ያስጀምራል። ሎጎዎችን `docker compose logs -f bot` ያስተውሉ።

ማስታወቂያ፡ የተወሰነ ራሱን ማዳመጫ systemd አገልግሎትን ያስፈልጋል፣ ስለዚህ Docker ውስጥ ማዳመጫዎች በእጅ ነው፡ `git pull` እና ደግሞ `docker compose up -d --build`።

Anthropic የተወሰነ ኤፒአዊ ኤፒአዊ OpenAI-ያዊ አይደለም፣ ስለዚህ ቦቱ በቀላሉ ከዚያ አይደርግም። OpenRouter ይጠቀሙ (የClaude ሞዴሎችን በOpenAI-ያዊ API ማግኘት የሚችል)፣ ወይም ከዝርዝሩ ሌላ አቅራቢ ይምረጡ።

**የወቅታዊ ፈርግ ሊሰራ አይችልም.**
የወቅታዊ ፈርግ SearXNGን ያስፈልጋል፣ ይህንም አስተጋብር Docker ጋር ለማዘጋጀት ያስቀምጣል። ይህ ካልነበረ ቦቱ ወደ Wikipedia ይመለሳል፣ ይህም የተጠበቀ ነው። ደግሞ `SEARCH_PROVIDER=tavily` ወይም `serper` ከ`.env` ጋር `SEARCH_API_KEY` ማድረግ ይቻላል።

**ሎጎች የት አሉ?**
`journalctl -u vortex-bot -f` የሕይወት ሎግን ያሳያል። `systemctl status vortex-bot` አገልግሎቱ እየተካሄደ እያለ ያሳያል። ቦቱ ቢቆይ፣ `sudo systemctl restart vortex-bot` ያድጋል።

**ቦቱ የቀኑን ገደብ ደርሶአል ይላል.**
ሁሉም ተጠቃሚ 30 የቦት ምላሾች በቀን ያገኛሉ (ባለቤቱ አልተጠበቀበትም)። ገደብው በቦቱ የአገር ጊዜ የጠዋት ሰዓት ይተካል። በ`.env` `DAILY_LIMIT_MESSAGES` ያስጨግቡ፣ ወይም ባለቤቱን ጠይቁ።
