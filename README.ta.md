## Vortex என்றால் என்ன?

Vortex உங்கள் குழுக்களிலும் தனியார் அரட்டைகளிலும் வாழும் ஒரு டெலிகிராம் போட், AI அரட்டை மாதிரியைப் பயன்படுத்தி மக்களுக்கு பதிலளிக்கிறது. நீங்கள் அதன் பெயரைக் கூறினால் (முன்னிருப்பு பெயர் **Vortex**) அது பதிலளிக்கும் — அது அரட்டை செய்யலாம், வலைதேடல் செய்யலாம், படங்கள் உருவாக்கலாம், விலைகளைச் சரிபார்க்கலாம், நகைச்சுவைகள் சொல்லலாம், கோப்புகளை படிக்கலாம், குரல் செய்திகளை எழுத்தாக்கலாம், மற்றும் இன்னும் பலவிதம் செய்யலாம்.

இது உங்கள் சொந்த சேவையகத்தில், உங்கள் சொந்த நாட்டிலும் மொழியிலும் இயங்குகிறது. நீங்கள் தலைமை: ஒரு மறைந்த `/admin` பலகை AI சாவிகள், பயனர்கள், மற்றும் அமைப்புகளை நிர்வகிக்க அனுமதிக்கிறது.

## அம்சங்கள்

- 💬 **AI அரட்டை** குழுக்களில் (எழுப்புச் சொல்) மற்றும் தனியார் அரட்டைகளில் (எழுப்புச் சொல் தேவையில்லை)
- 🔑 **Token pool** — பல LLM வழங்குநர்கள் மற்றும் கீஸ் பயன்படுத்தவும், தானாகவே மாறவும் மற்றும் தோல்வி நேரம் மாற்றவும்
- 🖼️ **படம் உருவாக்கல் மற்றும் திருத்தல்** — இலவசம் (DuckAI) அல்லது பணம் செலுத்தும் வழங்குநர்கள்
- 🔍 **வலைத் தேடல்** — தனது சேவையகத்தில் 호ஸ்ட் செய்யப்பட்ட SearXNG, Wikipedia பின்சேமிப்பு உடன்
- 💰 **நேரடி விலைகள்** — உங்கள் உள்ளூர் நாணயத்தில் நாணயங்கள், தங்கம், எண்ணெய், மற்றும் கிரிப்டோ
- 🕌 **நமாஜ் நேரங்கள்**, 🃏 **பால்கள்**, 😄 **நகைச்சுவைகள்**, 🎲 **பாசா மற்றும் நாணய உலுக்கல்**
- 📎 **கோப்பு பகுப்பாய்வு** மற்றும் **குரல் எழுத்தாக்கம்**
- 📥 **பதிவிறக்கங்கள்** — ஒரு இணைப்பை அனுப்பவும், ஊடக கோப்பை திரும்பப் பெறுங்கள் (45 MB வரை)
- 🌍 **195 நாடுகள்** மற்றும் **40 மொழிகள்** — நாடு மற்றும் மொழி தனித்தனி அமைப்புகள்
- 🔄 **தானாகவே புதுப்பிக்கும்** — தினமும் புதிய வெளியீடுகளைச் சரிபார்த்து, புதுப்பிக்கும் முன் உங்களிடம் கேட்கும்
- 🛡️ **மறைந்த /admin பலகை** — டோக்கன்கள், பயனர்கள், புள்ளிவிவரங்கள், அரட்டைகள், பட மாதிரி, மேலாளர்கள், சக்தி

## நிறுவுவதற்கு முன்

உங்களுக்கு ஒரு சேவையகம் (அбо ஒரு எப்போதும் இயங்கும் கணினி) **Linux** உடன் இயங்க வேண்டும், இவற்றை நிறுவியிருக்க வேண்டும்:

| என்ன | எப்படி சரிபார்க்கலாம் | நீங்கள் என்ன காண வேண்டும் |
| --- | --- | --- |
| **Python 3.11 அல்லது புதியது** | `python3 --version` | `Python 3.11.x` அல்லது அதற்கு மேல் (3.12 மற்றும் 3.13 வேலை செய்யும்) |
| **git** | `git --version` | `git version 2.x.x` |
| **curl** | `curl --version` | `curl 7.x.x` அல்லது `8.x.x` |
| **systemd** | `systemctl --version` | `systemd 24x` அல்லது அதேபோல் |
| **Docker** *(விருப்பம்)* | `docker --version` | `Docker version 2x.x.x` — விருப்பமான SearXNG வலைத் தேடல் வேண்டியபோது மட்டுமே தேவை |

ஏதாவது காணவில்லை என்றால், நிறுவுநர் `apt` (Debian/Ubuntu-இல்) மூலம் உங்களுக்காக அதை நிறுவ முன்மொழிவிக்கும். மற்ற அமைப்புகளில், உங்கள் தொகுப்பு நிர்வாகியைப் பயன்படுத்தி முதலில் நிறுவவும்.

நீங்களுக்கு Telegram-இல் இருந்து இரண்டு விஷயங்கள் வேண்டும் (இரண்டும் இலவசம்):

1. **ஒரு போட் டோக்கன்** — Telegram-இல் [@BotFather](https://t.me/BotFather)-உடன் பேசுங்கள், `/newbot` அனுப்புங்கள், மற்றும் அது வழங்கும் டோக்கனை நகலெடுக்கவும்.
2. **உங்கள் எண் வடிவில் உள்ள Telegram பயனர் شناسه** — [@userinfobot](https://t.me/userinfobot)-உடன் பேசுங்கள் மற்றும் அது காட்டும் எண்ணை நகலெடுக்கவும். இது உங்கள் "தலைமை" شناسه: மட்டுமே இந்த கணக்கே `/admin` பயன்படுத்த முடியும்.

## நிறுவல்

ஒரு கட்டளை. அதை நகலெடுக்கவும், உங்கள் டெர்மினலில் ஒட்டவும், மற்றும் Enter அழுத்தவும்:

```bash
curl -sSL https://raw.githubusercontent.com/VortexLabsHQ/vortex-telegram-bot/main/install.sh | bash
```

ச்தாபநர் உங்களிடம் ஆறு கேள்விகளைக் கேட்கும், வரிசையில்:

1. **நாடு** — உங்கள் நாட்டின் ஆங்கில பெயரை **கீழே உள்ள [நாட்டு அட்டவணையில்](#countries) உள்ளதைப் போலவே** ஒட்டவும் (எடுத்துக்காட்டு `Turkey`). நாடு நேர வலையம், விலைகளுக்கான உள்ளூர் நாணயம், நமஸ்கார நேரங்கள், மற்றும் உள்ளூர் உள்ளடக்கத்தை அமைக்கிறது.
2. **மொழி** — போட் பேசும் மொழி (எடுத்துக்காட்டு `en`, `fa`, `tr`). உங்கள் நாட்டிற்கான முன்னிருப்பை ஏற்றுக்கொள்ள Enter அழுத்தவும். மொழி நாடிலிருந்து வேறுபடுகிறது: இது போட் என்ன சொல்லுகிறது என்பதை மட்டும் மாற்றுகிறது, மேலும் நீங்கள் `/admin` மூலம் பின்னர் மாற்றலாம்.
3. **போட் டோக்கன்** — [@BotFather](https://t.me/BotFather) இருந்து டோக்கனை ஒட்டவும். நிறுவி இதை Telegram-இல் நேரடியாக சரிபார்க்கும்.
4. **பாஸ் எண்ணியல் ஐடி** — [@userinfobot](https://t.me/userinfobot) இருந்து உங்கள் Telegram பயனர் ஐடி.
5. **போட் பெயர் / விழிப்புச் சொல்** — குழுக்களில் போட் உடன் பேச மக்கள் சொல்லும் பெயர். எந்த மொழியும் சரி (எடுத்துக்காட்டு `Vortex` அல்லது `ورتکس`). முன்னிருப்பு `Vortex` க்கு Enter அழுத்தவும்.
6. **முதல் LLM வழங்காளர்** — ஒன்றைத் தேர்ந்தெடுக்கவும்: OpenAI, Anthropic, OpenRouter, Google AI (Gemini), DeepSeek, Groq, Together AI, Mistral AI, xAI (Grok), Cohere, அல்லது **தனிப்பயன்** (அடிப்படை URL ஐ ஒட்டவும்). பின்னர் அந்த வழங்காளருக்கான உங்கள் API кľூச்சியை ஒட்டவும் — நிறுவி வழங்காளரின் நேரடி மாதிரி பட்டியலைப் பெறுகிறது மற்றும் நீங்கள் ஒரு மாதிரியைத் தேர்ந்தெடுக்கிறீர்கள்.

பின்னர் நிறுவி சார்புகளை நிறுவுகிறது, `.env` கோப்பை எழுதுகிறது, `vortex-bot` systemd சேவையை உருவாக்குகிறது, வலை தேடலுக்கான SearXNG நிறுவுவதை முன்மொழிக்கிறது (Docker தேவை), மற்றும் போட் தொடங்குகிறது.

> ⚠️ **Anthropic நேரடியாக வேலை செய்யாது.** Anthropic-এর 기본 API OpenAI-உத்தரவாதியாக இல்லை, மற்றும் இந்த போட் மட்டும் OpenAI-உத்தரவாதி API-கள் மட்டும் பேசுகிறது. நீங்கள் Anthropic ஐ தேர்ந்தெடுத்தால், நிறுவி எச்சரிக்கை தருகிறது: கீ மட்டும் OpenAI-உத்தரவாதி வாயிலின் மூலம் வேலை செய்யும். அதற்குப் பதிலாக OpenRouter, அல்லது பட்டியலில் இருந்து மற்றொரு வழங்காளரைப் பயன்படுத்தவும்.

## நிறுவல் பின்

போட் இயங்குகிறதா என்பதைச் சரிபார்க்கவும்:

```bash
systemctl status vortex-bot
```

நீங்கள் `active (running)` என காண வேண்டும். நேரடி Nhậtچத்திரத்தை பார்க்க:

```bash
journalctl -u vortex-bot -f
```

இப்போது Telegram-ஐ திறந்து உங்கள் போட் உடன் സംவதிக்கவும்:

- `/start` அனுப்பவும் — போட் வணக்கம் சொல்லும்.
- **தனிய உரையாடலில்**, அதற்கு நேரடியாக எழுதவும் — விழிப்புச் சொல் தேவையில்லை.
- **குழுவில்**, போட் குழுவில் சேர்த்து, பின்னர் அதன் பெயரைக் கொள்ளுங்கள், எடுத்துக்காட்டு: `Vortex what's the time?`
- பாஸ் என்னும் நீங்கள், தனிய உரையாடலில் `/admin` அனுப்பி மறைக்கப்பட்ட நிர்வாக பலகையை திறக்கவும்.

**புதுப்பிப்புகள் தானாக நடക്കின்றன.** ஒருநாளில் ஒரு முறை போட் GitHub-இல் புதிய வெளியீடு உள்ளதா என்பதைச் சரிபார்க்கிறது. ஒன்று கிடைத்தால், அது உங்களுக்கு ✅ / ❌ பொத்தான்களுடன் தனிய செய்தி அனுப்பும். ✅ ஐ தட்டவும் அது தானாக புதுப்பித்து மறுதொடக்கம் செய்யும் — நீங்கள் சேவையகத்தை எப்போதும் தட்டத் தேவையில்லை.

## உள்ளமைவு

அனைத்து அமைப்புகளும் நிறுவல் அடைவில் உள்ள `.env` கோப்பில் உள்ளன. ஒவ்வொரு விருப்பத்திற்கும் [`.env.example`](.env.example) ஐப் பார்க்கவும். மிக முக்கியமானவை:

| Setting | என்ன செய்கிறது |
| --- | --- |
| `BOT_TOKEN` | உங்கள் டெலிகிராம் போட் டோக்கன் (@BotFather இருந்து) |
| `BOSS_ID` | உங்கள் எண்ணிக்கை டெலிகிராம் பயனர் ஐடி (போட் உரிமையாளர்) |
| `BOT_NAME` | போட் பெயர் மற்றும் குழுக்களில் விழிப்புத் தேர்வு (முன்னிருப்பு `Vortex`) |
| `BOT_COUNTRY` | ஆங்கிலத்தில் நாடு, உதா. `United States` (நேர வலயம், நாணயம், நமஸ்கார நேரங்கள் அமைக்கிறது) |
| `BOT_LANGUAGE` | போட் மொழி குறியீடு, உதா. `en`, `fa`, `tr` (போட் என்ன சொல்லுகிறது மட்டும் மாற்றுகிறது) |
| `LLM_PROVIDERS` | LLM வழங்குநர்கள் மற்றும் கீங்கள்: `base_url\|api_key\|model`, காமா விலக்கப்பட்டவை |
| `UPDATE_CHECK_ENABLED` | `1` = தினமும் புதுப்பிப்புகள் சரிபார்க்க, `0` = ஒருபோதும் சரிபார்க்காது |
| `UPDATE_REPO` | வெளியீடுகள் கண்காணிக்கப்படும் repo (முன்னிருப்பு `VortexLabsHQ/vortex-telegram-bot`) |
| `SEARCH_PROVIDER` | வலை தேடல்: `searxng` (முன்னிருப்பு), `tavily`, அல்லது `serper` |
| `DAILY_LIMIT_MESSAGES` | பயனர் ஒவ்வொரு நாளும் அதிகபட்ச போட் பதில்கள் (முன்னிருப்பு `30`, boss தவிர்க்கப்பட்டவர்) |

நாடு மற்றும் மொழி பின்னர் `/admin` பேனலில் (மொழி & நாடு) இருந்து மாற்றலாம், எந்த கோப்பையும் திருத்தாமல்.

## Docker மாற்று

நிறுவனர் மேல் Docker ஐ விரும்பினால்:

```bash
cp .env.example .env   # fill in BOT_TOKEN, BOSS_ID, and your LLM key(s)
docker compose up -d --build
```

இது தன்னிறக்கம் SearXNG தேடல் இயந்திரத்துடன் போட் தொடங்குகிறது. `docker compose logs -f bot` மூலம் لاக்கள் பார்க்கவும்.

குறிப்பு: தானியக்க தன்னிறக்க புதுப்பிப்பாளர் systemd சேவையை தேவைப்படுத்துகிறது, எனவே Docker இல் புதுப்பிப்புகள் கைமுறையாக: `git pull` மற்றும் பின்னர் மீண்டும் `docker compose up -d --build`।

## அம்சங்கள் விரிவாக

### /admin பேனல்

தனிய உரையாடலில் `/admin` அனுப்பவும் (boss மட்டும் — மற்றவர்களால் திறக்க முடியாது, மற்றும் `/help` அல்லது மெனூகளில் தோன்றாது). இதில்:

- 🔑 **Tokens & model** — LLM கீங்கள் சேர்க்கவும் அல்லது நீக்கவும், எந்த கீங்கள் ஆரோக்கியமானவை என்பதைக் காணவும், செயலில் உள்ள மாதிரியைத் தேர்வு செய்யவும், ஒரு வழங்குநரின் நேரடி மாதிரி பட்டியலை உலாவவும்
- 👥 **Users** — பயனர் எண்ணிக்கை, தடை / தடை நீக்கு, அனுமதிபட்ட பட்டியல்
- 📊 **Stats** — பயன்பாடு எண்கள்
- 💬 **Recent chats** — மக்கள் போட் என்ன சொன்னார்கள் (boss மட்டும், தனியார்)
- 🖼️ **Image model** — DuckAI (மiễnம், முன்னிருப்பு), HiLinkUp, ஒரு தனிப்பட்ட படம் சேவை, அல்லது 끔
- 🛡️ **Managers** — நம்பகமானவர்களுக்கு பேனல் பகுதிகளில் அணுகல் கொடுக்கவும்
- 🟢/🔴 **Power** — அனைவருக்கும் போட் ஆன்/ஆஃப் செய்யவும் (boss கட்டுப்பாட்டில் இருக்கும்)
- 🌍 **Language & Country** — போட் மொழி அல்லது நாடு எப்போதும் மாற்றவும்

### டோக்கன் குளம்

போட் பல LLM வழங்குநர்களின் கீங்களைக் கொண்டிருக்கலாம். அது ஆரோக்கியமான கீங்களுக்கிடையே சுழற்சியாகவும், ஒன்று நிறுத்தப்பட்டால் தானாகவே மறுபடியே மாற்றவும் செயல்படுகிறது. `/admin` இருந்து ஒரு மாதிரியை பிணைக்கலாம், கைமுறையாக மாதிரியைத் தேர்வு செய்யலாம், அல்லது போட் சுதந்திரமாக சுழற்சிக்க அனுமதிக்கலாம். OpenAI-உத்தரவாதி API உடைய எந்த வழங்குநரும் வேலை செய்கிறது — சிறு கூட்டுப்பயனர்கள் மட்டுமல்லா, பெரிய பெயர்களும்.

## பிரச்சினை தீர்வு / FAQ

**தொகுப்பு உங்கள் டோக்கன் செல்லாது என்று கூறுகிறது.**
டோக்கன் [@BotFather](https://t.me/BotFather) இருந்து வருகிறது. நீங்கள் முழு டோக்கனை நகலெடுத்துள்ளீர்களா என்பதை உறுதிசெய்யவும் (எண்கள், ஒரு முப்பெருக்கம், பின்னர் 35+ எழுத்துகள்), கூடுதல் இடைவெளிகள் இல்லாமல். நீங்கள் போட்டை நீக்கினால் அல்லது புதிய டோக்கன் உருவாக்கினால், பழையது வேலை செய்யாது — புதியதை ஒட்டவும்.

**போட் என் குழுவில் பதிலளிக்கவில்லை.**
மூன்று விஷயங்களை சரிபார்க்கவும்: (1) போட் குழுவில் சேர்க்கப்பட்டிருக்க வேண்டும், (2) நீங்கள் அதன் எழுச்சொல்லை சொல்ல வேண்டும் — அதன் பெயர், உதாரணமாக `Vortex what's the time?` — குழுக்களில் அதன் பெயர் சொல்லப்படும் போது மட்டும் போட் கேட்கிறது, (3) தனியார் அரட்டையில் எந்த எழுச்சொல்லும் தேவையில்லை.

**போட் ஆங்கிலத்தில் பதிலளிக்கிறது, என் மொழியில் அல்ல.**
`/admin` (போஸ் மட்டும்) → மொழி & நாடு என அனுப்பி, உங்கள் மொழியைத் தேர்ந்தெடுக்கவும். தொகுப்பும் மொழியைக் கேட்கிறது — உங்கள் நாட்டின் முன்னிருப்பை ஏற்றுக்கொள்ள அங்கு Enter அழுத்தவும்.

**நான் Anthropic ஐ தேர்ந்தெடுத்தேன் ஆனால் போட் அரட்டையாடவில்லை.**
Anthropic இன் உடன் API OpenAI-உத்தரவாதியாக இல்லை, எனவே போட் அதோடு நேரடியாக அரட்டையாட முடியாது. OpenRouter ஐப் பயன்படுத்தவும் (OpenAI-உத்தரவாதியான API மூலம் Claude மாதிரிகளை வழங்கலாம்), அல்லது பட்டியலில் இருந்து வேறு வழங்கியைத் தேர்ந்தெடுக்கவும்.

**வலை தேடல் வேலை செய்யவில்லை.**
வலை தேடலுக்கு SearXNG தேவை, இதை தொகுப்பு Docker உடன் அமைக்க வழங்குகிறது. இல்லாமல், போட் விக்கிப்பீடியாவுக்கு மீள்கிறது, அது பலவீனம். நீங்கள் `.env` இல் `SEARCH_API_KEY` உடன் `SEARCH_PROVIDER=tavily` அல்லது `serper` எனவும் அமைக்கலாம்.

**நோட்கள் எங்கே?**
`journalctl -u vortex-bot -f` நேரடி நோட்டைக் காட்டுகிறது. `systemctl status vortex-bot` சேவை இயங்குகிறதா என்பதைக் காட்டுகிறது. போட் நிறுத்தப்பட்டால், `sudo systemctl restart vortex-bot` அதை மீண்டும் தொடங்குகிறது.

**போட் நான் நாள் வரம்பை அடைந்தேன் என்று கூறுகிறது.**
ஒவ்வொரு பயனருக்கும் நாளில் 30 போட் பதில்கள் கிடைக்கும் (போஸ் தவிர்க்கப்பட்டிருக்கிறார்). வரம்பு போட்டின் நாட்டின் நேர வலையில் நள்ளிரவில் மீட்டமைக்கப்படுகிறது. `.env` இல் `DAILY_LIMIT_MESSAGES` உடன் அதை அதிகரிக்கவும், அல்லது போஸிட் கேளுங்கள்.

**நான் ஒரு பிழையைக் கண்டேன் / எனக்கு ஒரு யோசனை உள்ளது.**

## உருவாக்கம்

```bash
git clone https://github.com/VortexLabsHQ/vortex-telegram-bot.git
cd vortex-telegram-bot

python3.11 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
pip install ruff

cp .env.example .env   # then fill in your own BOT_TOKEN and LLM key(s)
python -m bot.main
```

சோதனைகளை இயக்கவும் (சாதாரண Python ஸ்கிரிப்ட்கள், pytest தேவையில்லை):

```bash
python tests/test_fixes.py
python tests/test_installer.py

```
